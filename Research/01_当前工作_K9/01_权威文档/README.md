## 3. 口径优先级（文档之间冲突时）

1. **仓库源码** `src/domain/drift_v6/creep_observer.{h,cpp}`（快照见 `../00_源码本体/`）；
2. `抗时漂v3.4_算法代码说明与移植指南.md`（明确声明"以 C++ 源码为唯一权威口径"）；
3. `K9_嵌入式迁移说明.md`（同样声明以源码为准）；
4. `算法说明_v3.4观测器.md`（声明"源码为唯一事实来源"）；
5. 其余文档（含论文体主文档）。

**已知的两处偏差**：

- `在线双态蠕变观测器补偿算法.md` 的空载判据仍是 K7 之前的 `idle = y < fade·y_max`；
  K7 之后实际用的是**去趋势门** `y0 − y_floor < idle_frac·(y_max − y_floor)` + **全局总值旁路**。
- `观测器嵌入式移植文档.md` 是 K6/K7/K9 之前的版本（5 个 float/通道；现在是 11 个）。
