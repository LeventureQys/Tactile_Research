## 1. 三十秒版

| 项 | 值 |
|---|---|
| 产品实现 | `src/domain/drift_v6/creep_observer.{h,cpp}` → `drift_v6::CreepObserverCompensator`（+ `CreepObserverCoordinator`） |
| 菜单 | 设备 → **时漂/零漂补偿（v3.4 观测器）** |
| 落盘 | `algorithm.id = drift_v34_creep_observer`，`param_set = **plan-v4 observer-k9**` |
| 参数 | **27 项**；其中 **8 项** UI 可调 + 下发设备寄存器 **200（使能）~ 208** |
| 每通道状态 | **11 个标量**（`x_fast / x_slow / v_lp / zero / y_max / t_edge / applied / v_fast_lp / y_floor / load_dwell / ramp_dwell`）+ 4 个全局 |
| 原理 | `y = v − zero`；`e = max(y − x1 − x2, 0)`；**显示 = `v − x1 − x2`（经 K6 预留池）** |
| 帧率/时间基 | 自适应 `dt`（钳到 ≤0.1 s），**不要求固定采样率**；帧内无动态分配、无查表、无环形缓冲 |

**四层增量各修一个现场失效**（顺序即落地顺序）：

| 层 | 修什么 | 怎么修 |
|---|---|---|
| **H3** | 阶跃后 ~2 s 见峰随后回落（纯过补偿中位 262 ADC） | 沿后 2 s 内 τc1→2 前馈；`τ_slope 3→1`；`slope_gate 2%→5%`；沿后 x2 **软冻结**（`1−exp(−t/4s)` 过半才开积分） |
| **K6** | 快相期间显示被往下拉太猛 | 显示侧维护**预留池** `applied`：受载期增速 ≤ 快速低通导数 + `hold_eps`，慢相随输入爬升逐步释放；空载直通 |
| **K7** | 反复 4~6 s 加卸载时补偿逐循环棘轮增长、空载塌向 0 | ① `slow_confirm_s` 连续受载确认；② 空载 `tau_r_slow_idle_s` 快泄放；③ **去趋势**空载门（`y_floor`）；④ **全局总值旁路**（迟滞双门限，防抖） |
| **K9** | 缓坡加载（0.5 < slope ≤ 60 ADC/s）不触发沿 ⇒ 只能走慢收敛 | 每通道 `ramp_dwell` 计时；`w = min(ramp_dwell/ramp_full_s, 1)`；`tc1 = tc1·(1−w) + tau_c_fast_boost_s·w`；斜率归零或越沿自动清零 |

## 3. 现场调参现状（2026-09-27）

- **首件参数表已产出**，按部位分三档（四指/拇指指腹、左手掌、右手掌），四指指尖待定：
  见 `02_现场调参/09-27_首件参数列表/9.27 首件算法参数列表.xlsx`，数值转录在根 `README.md` §3.3。
- **力值（N）显示模式与 ADC 显示模式的语义差别**是本轮最大发现（详见
  `02_现场调参/09-26_09-27_工程B_手掌/手掌_力值模式_8参数终版与代价.md`）：
  `e ≪ 1` ⇒ `base = max(e,1) ≡ 1` ⇒ `slope_cap_frac` / `r_slow_max` 从**比例语义**退化为**绝对语义**；
  且逐通道 `max|slope|` 只有 0.574 N/s ⇒ **触发沿 0 帧、触发缓坡 0 帧**
  ⇒ `τc1` 恒为 `tau_c_fast_s`，`t_edge` 恒 1e6 使 `soft_unfreeze_s` 门恒开。
  **换显示模式必须重新标定这 8 个参数。**
- **8 个旋钮在力值模式下的分工**（其余为空转）：
  | 旋钮 | 角色 |
  |---|---|
  | `r_fast` × `tau_c_fast_s` | 唯一的"电平扣除"（性价比最高） |
  | `slope_cap_frac` | 唯一的"跟踪速度 / 伪影闸门"——**上漂与回调在此互为代价** |
  | `slow_confirm_s` | ≤2 s 死区，≥3 s 纯推迟 |
  | `soft_unfreeze_s` | **死参数**（0.1~60 四位小数完全相同） |
  | `r_slow_max` | ≥0.1 空转；<0.08 变成"总扣除预算" |
  | `tau_r_fast_s` / `tau_r_slow_idle_s` | 只管卸载/重载衔接 |
