> 数据：`temp/算法数据&原始数据/working/零基线-反复增减同一负载/20260919_160854_single_device_7b3977`
> （21 通道 ADC 显示域，31306 帧 ≈ 311.8 s，现场参数集 plan-v3.0 PCT）
> 结论以 `src/domain/drift_v6/drift_v6_compensator.{h,cpp}` 当前源码为准。

## 1. 用户报障

1. **245 s 之后"丢基线"**：整片卸载（239.1~240.6 s，4 级台阶 ~1.5 s 塌到基线）后重新加载
   （244.3~245.9 s），显示的形状不再像 15 s 之后的加载段——15 s 一族"拿到阶跃之后保持完整性"，
   245 s 一族显示 ≈ 原始输入。
2. **一致性差距大**："后续没有补偿的位置"（245 s 后）与"前面有补偿的位置"（15~239 s）
   同一负载显示相差很大。

## 2. 定因（用真实 C++ 本体回放 pre 流，逐帧内部状态，见 `results/v34_replay_*.txt`）

### 定因 A：整片卸载把慢相补偿全部清空，重载从零估计

- 239~240 s 整片卸载：检测器 240.08 s 才确认 Decrease（此时输入已塌到 1841）→
  Reanchor（240.42）→ **ToIdle（240.86）清空 `pct_ded_`/`A_`/`g_`/掩码**。
- 244.3~245.9 s 重载作为**全新 Onset**：形状反演 Â≈14460，Handoff 锚定
  `A = y0 + share·Â ≈ 17048`（快相终点电平）——**把整段受载历史（239 s）累积的
  蠕变补偿（~2000 ADC）全部遗忘**。
- 后果：245 s 后显示 = 输入 + C 限幅帽（+0.5%），扣除 ≈ 0；而 15 s 一族
  显示 = 输入 − 累积补偿（1005→1540→1800→2316 随 load1 的持续蠕变增长，**这是正确行为**：
  load1 从 2.4 s 一直压到 239 s，其蠕变一直在累积）。
- **两族 A 相差 ~2000 ADC** —— 即用户看到的"一致性差距"。逐段中位（mem OFF 臂）：

### 定因 B（次要）：为什么"15 s 形状好"

15 s 的重载走 Restep/RestepReload 路径，`y0/c0` 继承机制保持扣除连续
（A_new = 上一段显示 + 增量 Â），扣除逐代累积；245 s 的重载从 Idle 出发没有这一血统。
机制本身没坏——坏的是**整片卸载把血统剪断后没有等价的记忆机制**。

## 3. 修复（plan-v3.4 creep-mem，已落地 `drift_v6_compensator.{h,cpp}`）

**蠕变记忆**：Decrease 事件建立当帧（慢相状态尚未被 Reanchor 侵蚀，
`freeze_slow_on_hit` 已挡住确认期自适应）快照：

- `mem_ded_` = 正在施加的总扣除向量（rank-1 + PCT，`DeductionVector()`）；
- `mem_lv_` = 检测器参考窗电平（塌落前电平）；`mem_ts_` = 快照时刻；
- **单调不缩水**：新快照与衰减后旧记忆取逐通道 max（反复快卸快装时重锚/事件细分
  每次都漏一小截，直接换新会让记忆逐代缩水，实测 4 个循环 1386→329）。

**应用（残差口径，`CreepMemory()`）**：非 Decrease 事件均可参与，自限不双计：

```
目标记忆 = mem_ded_⁺ · s · e^(−Δt/τ_mem)，s = (base+Â)/mem_lv_（按当前受载电平折减）
残差     = 目标记忆 − 显示血统已嵌入扣除（= base − base_y，即事件前"输入−显示"）
应用     = 残差 > 0 的部分，总量 ≤ 0.5·max(Â, base)
```

- Onset（Idle 出发，嵌入=0）→ 全额补齐；家族 A 的连续血统事件（嵌入≈全额）→ 自然为 0；
  楼梯式重载的后续 RestepReload 只补差额。
- 应用点两处，保持一致：**事件期滑行目标** `target = base_y + Â − mem`（显示在
  1~2 s 内直接滑到与历史补偿族一致的电平）与 **Handoff 锚定** `A = y0 + share·Â − mem`。
- 参数：`kMemTauS = 120 s`（静置衰减；0 = 关闭回到 plan-v3.1 行为）、
  `kMemMaxFrac = 0.5`；均可经 `Params` 运行期注入并随录制落盘
  （`param_set = "plan-v3.4 creep-mem"`，16 字段）。

## 4. 自决区（本轮自行裁决的取舍）

| 决策 | 备选 | 理由 |
|---|---|---|
| 记忆取 max 不缩水 | 每次快照直接覆盖 | 覆盖会让反复快循环的记忆逐代缩水（实测） |
| 残差口径（减血统嵌入） | 仅 Onset 应用 | 楼梯式重载的后续事件能补齐差额；家族 A 自动为 0，无需按 kind 分派 |
| 全额记忆（不按恢复比例打折） | 按 ~50% 保留率打折 | 目标是与家族 A 一致（实测全额差 ~180、50% 差 ~835）；恢复比例本身不可观测 |
| τ_mem=120 s | 30/60/300 s | 本批卸载间隙 1~6 s，衰减 <5%；真恢复时间未知，留参数现场调 |
