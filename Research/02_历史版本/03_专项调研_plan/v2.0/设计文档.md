## 1. 背景与目标（1~3 句）

现役时漂补偿算法 v6（`src/domain/drift_v6/drift_v6_compensator.{h,cpp}`，参数集 `plan-v1.0 A1+A4+A5a`）
在实机新录制上暴露两个缺陷：**① 加载沿后显示相对传感器读数出现 +4.6%·台阶（中位）的瞬态超前**；
**② 长保压期内显示偏移逐周期累积（实测 +808 → +1438 ADC），44 s 处一次交接把它显影、此后越飘越远**。
本版目标：在不破坏 plan v1.0 已验收行为的前提下，把 ① 压到 ≤1%·台阶、把 ② 的保压期偏移压到 ≤100 ADC，
并补齐 v6 落地以来缺失的单元测试与运行期参数可注入能力。

### 3.2 新增机制：谷底判据（valley）

三项修复都需要一个"当前是否已回到近期谷底"的判据。设计为**滚动窗相对判据**（不依赖"空载读数≈0"，
这与 T9 的 F1 不同：这里**不替换** `idle_now`，只是**新增**一个独立判据）：

```text
每帧（在 ts_smooth_ 更新之后、任何状态判断之前）更新长度 kValleyWinN 的环形缓冲（存 ts_smooth_）：
    w_min = 窗内最小 ts_smooth_ ; w_max = 窗内最大 ts_smooth_
    eps_v = 1e-6·(1 + |w_max|)
    valley_now_ = (ts_smooth_ < w_min + kValleyFrac·(w_max − w_min + eps_v))
                  && ((w_max − w_min) > kValleyRangeFrac·max(|w_max|, eps_v))
    valley_run_ = valley_now_ ? (valley_run_ + dt) : 0.0
```

- `kValleyWinN` = **4000 帧**（≈40 s @100 Hz；**按帧数**给定，与采样率解耦的口径见 §5.3）
- `kValleyFrac` = **0.15**、`kValleyRangeFrac` = **0.05**
- 语义：**"当前电平处于近 40 s 的谷底附近，且这 40 s 内确实发生过一次足够大的加载"**。
- 环缓实现复用 `.h` 既有风格（`kCap`/`kDcap` 的定长数组 + 计数），**不引入动态分配**。

### 3.3 逐项设计

#### C · 显示单侧限幅

- **位置**：`Process` 的三个输出点（`RunEvent` 返回后的 L376-384、慢相 L386-399、直通 L401-403）
  统一在**返回前**施加。实现方式：把 L379-382、L395-397、L401-402 的输出统一经过一个私有函数
  `ApplyOutputLimit(const Eigen::VectorXd& raw, Eigen::VectorXd* out) const;`
  （`out_i = min(out_i, raw_i + kClampAlpha·|raw_i|)`）。
- **为什么放在最后而不是 `RunEvent` 内**：`RunEvent` 返回 false 时会走到慢相/直通分支，
  只有出口统一施加才能覆盖全部路径；且限幅**不写任何内部状态**（与 `Capped` 同性质）。
- **实测收益**（`design_ab_verify.txt`、`probeh_filters.txt`、`probei_clamp_regress.txt`）：
  超前量峰值中位 **4.72% → 0.59%·台阶**、最大 13.27% → 0.75%；
  到带时间 T5% 中位 **4.78 → 2.51 s**；保压段偏移中位 **438 → 76 ADC**、最大 1273 → 455 ADC；
  13 份既有录制的时漂残余与 G **Δ=0.0000**（逐位不变）。
- **代价（必须写进验收）**：加载后 0.3~1.2 s 的"早期超前量"由 506 → 65 ADC（削掉约 87%）；
  长期蠕变抑制由"显示冻结"变为"显示约等于原始"，即**v6 的主动补偿能力被限幅接管**（机制性取舍，非缺陷）。

#### F2 · 事件期卸载出口

- **位置**：`RunEvent` L492 的 C4 出口**之前**，新增：
  ```
  if (params_.legacy_fixes_enabled && tau > params_.event_valley_min_s && valley_now_) {
      ++params_.n_valley_exit;
      ToIdle();
      *out = v;
      return true;
  }
  ```
- **理由**：E-3 实测 `idle_now` 在事件态内只真 1 帧 ⇒ 现役唯一卸载出口（L493）在本工况结构性不可达；
  `valley_now_` 只依赖近期电平形状，与"空载绝对值"无关。
- **⚠️ 默认开关（见 §3.4「设计期证据复核」）**：`Params::legacy_fixes_enabled` 默认 **false**（F2/F3 一并关闭），
  理由 = 14 份数据回归里 F2/F3 **收益未被证实、且在 1 份数据上方向不一致**。
  开启方式：`params().legacy_fixes_enabled = true`（运行期可注入）。

#### F3 · `Reanchor` 回到谷底即归零

- **位置**：`Reanchor` L653 开头：
  ```
  if (params_.legacy_fixes_enabled && valley_now_ && valley_run_ >= params_.reanchor_valley_s) {
      ++params_.n_reanchor_idle;
      ToIdle();
      return;
  }
  ```
- **理由**：`Reanchor` 的"保持扣除连续"（L657-659 注释）会**原样继承错误扣除**；
  已回到谷底时继承的前提（"实测电平里含真实受载"）不成立。
- **默认值**：同上，默认关闭（与 F2 共用一个开关，便于整组 A/B）。

#### F5 · 慢相 `g` 的负向下界 + 谷底归零

- **位置**：`SlowStep` L713 更新 `g_` 之后：
  ```
  if (g_ < kGNegFloor) g_ = kGNegFloor;                    // kGNegFloor = −0.05
  if (valley_now_ && valley_run_ >= kGValleyResetS && g_ < 0.0) g_ = 0.0;   // kGValleyResetS = 0.30
  ```
- **理由**：`g < 0` 时 `ded = γ·A·g < 0` ⇒ `out = v − ded = v + |ded|`，显示被**抬高**（E-2）；
  本录制 `g` 极值 −0.499。
- **实测**：本录制 `g` 归零触发 384~388 次；`g_min` 由 −0.499 截到 −0.050。
  在 14 份数据回归里 F5 **无任何劣化**，并在新录制上给出 +0.0007 的额外 `resid` 改善（0.0351 → 0.0343）
  ⇒ **默认启用**。

#### P · 运行期参数注入

- **位置**：`.h` 中新增嵌套 `struct Params`
  （含本版全部新常量 + 既有 `kKappaOnset/kKappaRestep/kHoMinS/kRevokeHoldN`），
  `DriftV6Compensator` 增加 `const Params& params() const` 与 `void SetParams(const Params&)`；
  `Reset()` 恢复默认值。**既有 `static constexpr` 常量保留**（作为 `Params` 的默认值来源，避免改动既有引用点）。
- **接口契约**（下游 `data_handler.cpp`）：
  ```cpp

  obj["clamp_alpha"]           = comp.params().clamp_alpha;
  obj["valley_win_n"]          = comp.params().valley_win_n;

  double valley_buf_[kValleyWinN];      // .h 私有：环形缓冲存 ts_smooth_
  long   valley_n_   = 0;               // 累计写入帧数
  bool   valley_now_ = false;
  double valley_run_ = 0.0;             // 谷底连续时长（秒）
  void   UpdateValley(double dt);       // 在 ts_smooth_ 更新后调用

  // 私有函数（SubStage 2A 新增）
  void ApplyOutputLimit(const Eigen::VectorXd& raw, Eigen::VectorXd* out) const;
```

**生命周期/错误处理契约**：

- `UpdateValley` 在 `Process` 中于 `eps` 计算**之后**、检测器**之前**调用一次，**无论 dt 是否为 0**；
  `dt ≤ 0` 时 `valley_run_` 不累加（与既有 EMA 口径一致）。
- `Reset()`/`ResetFor()` 必须清零 `valley_n_`、`valley_now_`、`valley_run_` 与四个计数器。
  **★ 经 SubStage 4A 实测修正（见 §4.1.1 C-5）：`Reset()` 不再清 `params_`**——
  新语义为"`Reset()` 只重置补偿状态，不动运行期参数"；参数只由 `Params` 的默认成员初始化器与显式
  `SetParams()` 决定。原语义会让"首帧之前注入的参数"被首帧的 `ResetFor → Reset` 静默抹掉。
- `ApplyOutputLimit` **不写任何内部状态**；`raw` 与 `out` 尺寸不等时直接返回（不得越界）。
- 任何新增判据在"数据不足"（`valley_n_ < kValleyWinN`）时行为：`valley_now_ = false`（保守：不触发任何出口）。
- 不抛异常、不返回错误码；所有函数为 `void`/普通返回值，与既有风格一致。

### 5.2 与既有参数的关系（避免重复旋钮）

- `kClampAlpha` 与 `kKappaOnset` **不是同一个旋钮**：后者压 `Â`（内部估计），前者压输出（显示）。
  本版**不动** `kKappaOnset`（保持 1.05）。
- `kGNegFloor` 与 `kCreepLoFrac/kCreepHiFrac` 是不同层级：前者限制共识 `g`，后者限制逐通道扣除量。
- `valley_now_` 与 `idle_now`（L317-319）**并存**：`idle_now` 继续负责原有的建事件分类与慢相 ToIdle 出口，
  `valley_now_` 只用于 F2/F3/F5 三处。**不替换、不修改 `idle_now`**（T9 的 F1 已证会引入新回归）。

### 5.3 采样率说明（必须写进文档）

`kValleyWinN` 按**帧数**给定 ⇒ 100 Hz 链路下为 40 s，20 Hz 测试夹具下为 200 s。
**这是刻意的**：既有常量（`kDetPersist`、`kGlideMinS` 等）也混用帧与秒，
本版新增量一律**按帧**，以与 `kCap`/`kDcap` 一致的实现风格落地；
参数落盘时同时写 `valley_win_n`（帧）与 `valley_win_s`（按 100 Hz 折算的秒），由使用方按链路帧率判读。
