## 1. 方法（可复现）

### 1.1 临时 C++ 工程（已按任务要求删除，见 §6）

- 目录：`temp/v4.1flash/plan/v2.0/__scratch_int/`（**独立于主工程**，不参与 CMake）
- 编译：只编 `src/domain/drift_v6/drift_v6_compensator.cpp` + `int_verify.cpp`
  `cl /nologo /EHsc /utf-8 /std:c++17 /O2 /DNDEBUG /I src /I thirdparty/eigen-5.0.0`
  （与主工程一致的 `/EHsc /utf-8 /std:c++17`）
- 未使用任何主构建树，未执行任何 `cmake`/`ctest`，未构建或运行任何 `test_*` 目标，未启动 `TactileSense.exe`。

### 1.2 调用顺序（如实记录）

```cpp
DriftV6Compensator comp;
DriftV6Compensator::Params p;   // 逐项覆盖 clamp_alpha / legacy_fixes_enabled / g_neg_floor
comp.SetParams(p);              // ← 在喂第一帧之前
for (每帧) comp.Process(elapsed, v);
```

程序内断言：`Process()` 首帧返回后复查 `params().clamp_alpha / legacy_fixes_enabled / g_neg_floor` 与注入值逐位相等，未打印 `!! WARNING: params changed during first Process()` ⇒ **首帧 `ResetFor(n) → Reset()` 确实不再清 `params_`**（新契约成立，实测证据）。全过程未调用 `Reset()`（每配置使用全新实例）。

### 1.3 三配置（每个配置各跑一遍；A/C 另跑 1 次 `clamp_alpha=0` 的孪生运行用于测削幅）

| 配置 | `clamp_alpha` | `legacy_fixes_enabled` | `g_neg_floor` | 其余 |
|---|---|---|---|---|
| **A** 交付默认 | 0.005 | false | −0.05 | 全部默认常量 |
| **B** 基线（未接限幅，≈"只加 F5"） | 0.0 | false | −0.05 | 全部默认常量 |
| **C** 全开 | 0.005 | true | −0.05 | 全部默认常量 |

### 1.4 削幅测量法与独立复算

- 削幅（Q3）：对每个开启限幅的配置再跑一遍 **`clamp_alpha=0`**、其余参数完全相同的孪生运行（限幅只改输出、不改内部状态 ⇒ 孪生运行与限幅运行的内态逐帧相同），逐**格**（通道×帧）取 `未限幅输出 − 限幅输出 > 1e-9` 即"真实被削掉的格"。
- 独立复算：`int_cpp_analyze.py`（numpy，只读导出 CSV 与录制文件）重算了 Q1/Q4/Q5/Q6 与分段平台中位，与 C++ 侧程序内指标一致；并校验 `raw_total ≡ Σ ch`（最大偏差 0）。
- 可重复性：同一程序连跑 3 次，打印出的全部指标逐位相同（Q1 med/rms/median|d|、A/B/C 的 off/lead/resid/viol/clip、阳性对照数）⇒ 端到端结果确定、无随机性。
- A vs C 逐帧比对由导出 CSV 直接做差得到（不是由内部状态推断），差异量见 §3.3 的 F3 行。

## 4. 阳性对照（**必须做**，证明 Q2 断言不是恒真）

| 对照项 | 实测 | 说明 |
|---|---|---|
| **B 的输出（`clamp_alpha = 0.0`，不接限幅）对交付默认的界 `out ≤ raw + 0.005·\|raw\| + 1e-6`** | **311629 格违反**（/712068 格 = 43.8%） | **> 0 ⇒ 不变量断言非恒真**（Q2 的 0 是真实成立，不是恒真） |
| B 的输出对退化界 `α=0` | 375111 格违反 | 未接限幅时算法输出高于原始读数的格数 |
| A 的输出（已限幅）对更紧的界 `α=0.001` | 23988 帧（总量口径）违反 | 把界收紧到 1/5 立刻失效 ⇒ 0 违反与 `α=0.005` 强相关，非"界太松" |
| A 的输出对更紧的界 `α=0.0005` | 24222 帧违反 | 同上 |

结论：Q2 的 **0 违反** 是"限幅确实生效且不变量成立"的证据（同一份帧数据上，只要把界收紧 5 倍，违反立刻变成 23988 帧）。
