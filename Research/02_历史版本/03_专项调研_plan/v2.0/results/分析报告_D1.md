**连续性是可核算的「中位近似」，不是恒等式**：记旧扣除 `d_old(k) = γ_k·A_old·g_old`（在限幅内时成立，L616–617）。`Reanchor` 取 `A_k = vs_k − d_old(k)`（L664），随后令 `g_new = median_k( d_old(k) / (γ_k·A_k) )`（L671–676），`γ_k` 不变。于是新扣除
`d_new(k) = γ_k·A_k·g_new = d_old(k) · (γ_k·A_k·g_new / d_old(k)) = d_old(k) · (g_new / (d_old(k)/(γ_k·A_k)))`。
即 `d_new(k) = d_old(k)` 当且仅当**该通道的比值 `d_old(k)/(γ_k·A_k)` 等于全体中位数**。因此：所有受载通道比值相同（例如 `γ_k` 全相等）时连续性精确成立；`γ_k` 在限幅区间 `[kGammaMin, kGammaMax] = [0.3, 2.0]`（`.h` L149–150）内离散时，逐通道的相对偏差 = 该通道比值相对中位数的偏离。故 `.cpp` L658–659 注释「g 必须与当前扣除自洽（保持连续）」在实现上是**中位意义下的一阶自洽**（与 `Handoff` L638–643 是同一套近似）。

### 5.1 常量是否可运行期修改

**结论：当前全部不可运行期修改。** 01 文档 §7 涉及的所有参数都是 `static constexpr`（`.h` L76–L159），编译期常量：

按**改动量递增**列出三条路线，行号精确到点：

**路线 A（最小，推荐用于 A/B；改动面 = 3 处 + 序列化 1 处）**

1. `.h` L76–L159：把目标常量由 `static constexpr double NAME = V;` 改为**实例字段** `double NAME = V;`。
