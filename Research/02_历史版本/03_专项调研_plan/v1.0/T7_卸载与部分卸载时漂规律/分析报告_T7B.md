## 1. 结论速览

1. **真实的部分卸载只有 3 例，而不是 5 例**：T4-A 冻结表里 5 个 `partial_unload` 中有 2 个（`SW1@129.37`、`SW1@182.03`）实测是**全卸载**（自适应 post 窗测得减重 99.8% 电平 = 26273 / 27956 ADC，post 落在 55~58 ADC 本底），原因是它们的 post 窗 `[t0+4,t0+6]` 被紧随其后的加载沿压到。实测分档：**全卸载 16 / 部分卸载（20~80%）1 / 小减重（<20%）2**（`t7b_partial_amp_response.csv:kind_eff`）；这与第一轮 `b_unload_events.csv` 把两例判为 `full`（drop 26221 / 27932）一致。
2. **卸载幅度不决定回复速度**：两个幅度几乎相同的减重事件（15.0% 与 14.7% 电平）`t90` 相差 **17 倍**（0.01 s 对 0.17 s），而它们的**输入释放速度代理**相差 3.6 倍（`step_frame_frac` 1.73 对 0.48）；全样本 `Spearman(drop_frac, t90) = -0.099`（n=19，不显著）。⇒ 决定回复快慢的是**卸载输入本身的快慢**，不是幅度。
3. **全卸载在 1~3 个包内完成**：n=16，`t90` 中位 **0.015 s**（p10~p90 0.010~0.130），`f(0.2 s)` 中位 **1.002**；16 例中 **8 例 `t90` ≤ 1 个包周期**、12 例 ≤ 3 个包周期（包周期：实录 0.0401 s / 指尖 0.0188 s）⇒ 卸载瞬态基本处在**时间轴量化极限**，只能给上界。
4. **【核心裁决 · T7-Q8】对称性假设不成立（反对）**：同录制、`|J|` 相差 ≤15% 的加载/卸载配对 **n=15**，`t90_load / t90_unload` 中位 **24.0**（p10~p90 1.8~57.0；15 个比值排序 0.80 / 1.62 / 2.00 / 9.7 / 16 / 16 / 21 / 24 / 34 / 36 / 40 / 40 / 45 / 65 / 68.5）——**12/15 对比值 >= 9.7（最大 68.5）**，最严子样本 **27.4**，对对称性最有利的 **±1 包保守边界仍有 13.5 倍**。**必须如实报出的例外**：3 对（比值 0.80 / 1.62 / 2.00）无法支持不对称，其中 2 对的保守比值 ≤1（`SW1@185.97→SW1@129.37` 0.50、`SW4@88.00→SW4@113.80` 1.00），且全部只涉及本批数据里**最慢的两次减重**（`t90` 0.20 s / 0.13 s）。与包量化无关的完成度指标仍显著：`f(0.2 s)` 加载 **0.795** 对卸载 **1.004**（Mann-Whitney **p=1.8e-07**）。⇒ **T4-A 的 E2 证据（"卸载 0.2 s 完成 100.3% ⇒ 慢的不是传感器"）依赖的镜像假设被推翻，E2 不能再作为机制证据**（其结论方向不受影响，见 §4.2）。
5. **分层控制后 24 倍反差不是"输入不同"造成的假象**：加载侧按等效输入斜坡 `T_ramp` 分三层，`t90` 中位 **0.685 / 0.725 / 0.670 s**（n=22/8/10，几乎不变），而 `f(0.2 s)` 随 `T_ramp` 强烈下降 **0.829 → 0.608 → 0.431**：输入斜坡解释的是**起步段**，不是 `t90`。
6. **反向事件误判率为 0**：v6 对 **19/19** 个真实减重事件都在 ±1 s 内建立了 `decrease` 方向事件（±1 s 与 ±2 s 两窗口均为 **0%** 误判；邻近内部事件合计 `decrease` 19 次、`restep` 1 次）。**但基线幅值会错**：全卸载稳态偏差 0.000%（n=16）；20~80% 档 −2.25%/−2.30%·|J|（n=1）；小减重档 **−26.9%（v5.1，−999 ADC）/ −38.4%（v6，−1418 ADC）**（n=2，仅作定性参考）——v6 在 `SW4@45.28` 上显示比真实新电平低 **2195 ADC = 60.5%·|J|** 并持续整个 8 s 观测窗。
7. **7561 ADC 单帧跳变案例在本批数据上可精确复现，且同一机制在现役原型上仍存在于卸载沿**：archive 原型 CompV2 在 `SW3`（=changelog 的"数据B"）`t=23.83 s` 给出算法引入 **+7561.2 ADC**（同帧显示 +7563 / 原始 +2，与 2026-10-26 条目的 +7561 / +19 吻合）；现役原型在同批数据上的最大算法单帧跳变：**v5.1 1217~1824 ADC、v6 2682~5324 ADC**，其中 v6 的 **+5324 ADC 恰好出现在 `SW3@30.69 s` 的全卸载沿**（占该次减重的 20.5%）。

## 2. 方法与口径

### 2.1 方向统一口径（**本报告的时间指标全部按此，读者不会把符号差异误当机制差异**）

```
pre    = median Z on [t0-2, t0)                （加载前 / 卸载前电平）
post   = median Z on [t0+4, t0+6]              （对齐 00_共享/指标字典 §2.1 既有口径）
D      = post - pre                            （带符号：加载 D>0，卸载 D<0）
f(τ)   = (Z(t0+τ) - pre) / D                   （归一化进度，方向无关，0 → 1）
t_α    = f 首次 ≥ α/100 的 τ（α = 10/50/80/90/95）
```

加载与卸载**同式同判据**，因此 `t90_load / t90_unload` 的比值就是"同 `|J|` 下的时间常数比"。
`post` 窗被后续事件污染时改用**自适应窗** `[t0+1, t_next-1]`：`post_win_clean` 旗标按"是否存在其它冻结事件落在 `[t0+1.5, t0+8.5]`"置位，而自适应窗在 `t_next < t0+7 s` 时启用（`t_next` = 同录制内下一个事件起点）。自适应窗的取值逐事件记录在 `t7b_partial_amp_response.csv:post_win`。

### 2.2 事件集（**不重新检测事件时刻**）

* 事件时刻、`kind`、`pre/post/jump` 初值一律取 **T4-A 冻结表** `t4a_morphology.csv`（60 事件；其中 `SW3@60.78` 因后窗越界被 T4-A 标 `trunc`，本报告剔除，实际用 59 个）。
* 加载侧等效输入斜坡 `T_ramp`、`gain_ramp`、反卷积残差取 `t4a_input_recover.csv`（按 `key`+`t_on` 对齐）。
* **减重侧（`unload`/`partial_unload`）另做一次 T7-B 自建扫描**（`t7b_decrement_inventory.csv`）用于①补样本量、②对冻结表的标签做交叉验证。扫描口径：`pre - post` 落差 ≥5% 电平、局部极大、死时间 6 s、幅度 ≥ `max(2%·本录制 Z 峰值, 5σ_noise)`、pre/post 窗 MAD ≤ `max(2%·电平, 5%·|J|)`。**召回 17/19**（漏检的正是被 T4-A 标为 `partial_unload` 的两例全卸载：`SW1@129.37` 被 post 窗稳定门限剔除（post MAD 843 > tol 527）、`SW1@182.03` 属其它门限），扫描**没有发现任何冻结表之外的新减重事件**。

#### A.3 卸载幅度是否决定回复速度（T7-Q6 后半）

* 全样本（n=19 减重事件，含 16 个全卸载）：`Spearman(drop_frac_eff, t90_ad) = -0.099`（不显著）。
* 只取**低于 80% 的 3 例**：`t90` = 0.01 / 0.17 / 0.20 s，对应幅度 15.0% / 14.7% / 74.4% —— **同样 15% 的两例差 17 倍**，反而 74% 那例最慢。
* 与**输入释放速度代理**（`step_frame_frac` = 最大单帧跌幅 / |J|）对照：`SW1@202.65` 1.73（输入近乎一帧）→ `t90` 0.01 s；`SW4@45.28` 0.48（输入跨多帧）→ `t90` 0.17 s；`SW1@212.40` 0.38 → `t90` 0.20 s。三个非全卸载事件的 `t90` 排序与输入速度排序**完全一致**，与幅度排序不一致。
* **结论**：本数据 **n≤3 无法建立"幅度 → 回复速度"的函数关系**；可见的散布与卸载输入的快慢同向。要定论需补采（见 §5）。

### 4.2 与 T4-A 的 E2 机制证据（`分析报告_T4A.md` §3.3）——按 `00_共享/接口冲突登记.md` **C-5** 的显式回应

* **T4-A 的用法**：同录制同带载状态下的卸载在 0.2 s 完成 100.3%（`z_at_02` 中位 1.003，n=13），而同档 restep 只完成 0.594（n=5）⇒ 论证"**差别在输入而不在传感器**"。该论证**依赖"正负方向响应对称（线性粘弹性）"**（T4-A 已在未验证项中自曝）。
* **本席位的裁决**：该假设**不成立（反驳）**。同录制同 `|J|` 配对中位比值 **24**、最严子样本 **27.4**、对对称最有利的保守边界仍有 **13.5**；与包量化无关的 `f(0.2 s)` 差异 **p=1.8e-07**。物理上合理的解释是：加载存在黏弹蠕变（慢相），**卸载时这部分蠕变在 1~3 个包内一次性释放**，即"接触建立慢、解除快"的不对称。
* **对 T4-A E2 的影响**：**E2 不能再作为"慢的不是传感器"的机制证据**（卸载快 ≠ 传感器加载响应快），其证据强度应下调为"不成立（不作为证据）"。
* **对 T4-A 结论的影响**：**方向不变**。E1（onset 与 restep 的输入形状不同）、E3（通道起步同步性）、E4（反卷积 `T_ramp`：onset 0.010 s vs restep 0.550 s）都不依赖对称性；本席位另给出**独立的正向支持**：加载侧 `f(0.2 s)` 随 `T_ramp` 从 0.829 单调降到 0.431，说明"输入斜坡"确实是加载侧的支配变量。
* **给 T8 的评级建议**：T4-A「差别在输入不在传感器」= **支持（E1/E3/E4）**，但把 **E2 单列并降级**；不要再把"卸载 0.2 s 完成 100%"写成机制证据。

## 5. 未验证项与数据缺口

1. **20~80% 减重档 n=1**（`SW1@212.40`，74.4%），<20% 档 n=2 ⇒ **"卸载幅度 → 回复速度"无法定论**。需补采：**同一负载上 3~4 级递减台阶 × 至少 3 次重复**（例如 100% → 75% → 50% → 25% → 0），且每级保持 ≥10 s、间隔 ≥5 s。
2. **卸载瞬态落在 1 个包周期以内**（8/16 的 `t90 ≤ 1 包`）⇒ 无法判断"卸载是否在单包内完成、是否有自己的慢相尾巴"。需补采 **≥200 Hz** 或**保留包内逐帧时间戳**的录制（当前实录 4 帧共享一个时间戳，包内 4 帧的相对时序未知）。
3. **卸载侧没有等效输入斜坡 `T_ramp`**：T4-A 的反卷积只对 onset/restep 做过。本报告用**被动性上界**（单调系统的输出不可能快于输入 ⇒ 输出 `t90` 是输入 `t90` 的上界）替代，属**有前提的替代口径**；要做到与加载侧完全对等，需要把同一反卷积核套到卸载事件上（本席位未做，避免了核构造的循环性问题）。
4. **无标准力源、无"卸载后拆装"对照** ⇒ 无法区分"传感器黏弹残余"与"手指/夹具接触状态变化"；本报告的"部分卸载后回弹 30.8%·|J|"应读作"读数行为"，不是"材料性质"。
5. **显示域左拇指 3 例卸载后 post 恰为 0.000**（`LT1/LT2/LT3`），疑似显示层 `≥0` 钳位；这 3 例的卸载形状与 `t90` 可能被钳位改变。ADC 域无此问题（post 55~87 ADC），故**跨域结论以 ADC 域为准、显示域作交叉验证**。
6. **算法侧只跑了 Python 原型**（v5.1 / v6 / archive v2 的 CompV1·CompV2），未与 C++ 现行版逐帧对拍 ⇒ "v6 的 5324 ADC 卸载沿跳变在 C++ 侧是否同样出现"**未验证**（原型与 C++ 的参数一致性不在本席位范围）。
7. **注入实验的适用边界**：注入部分卸载靠线性叠加（把真实全卸载的 `|J|` 按比例加回），**只用于 §B 算法耦合**；它天然抹平"幅度对物理响应的影响"，因此**不能**用注入回答 Q6 的幅度-速度关系（若用，就是循环论证）。
8. **未覆盖**：不含 `SW3@60.78`（T4-A 标 `trunc`，后窗越界）；不含 T7-Q1~Q5/Q9；不含 C++ 侧参数核对；不含 v6.1（本轮原型链只到 v6）。
