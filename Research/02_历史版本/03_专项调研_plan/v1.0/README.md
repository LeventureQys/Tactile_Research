## 这次调研要解决的核心矛盾

一句话：**「1~2 s 稳定」与「读数不漂」在对快相的处理上正面冲突，v6 选了激进一侧并为此付了代价。**

- v5.1（现役）：快相**放任**（3 s 免责期）→ 稳（时漂 1.5%），但加载后 **3.8 s** 才稳定；
- v6：快相**抵抗**（形状约束反演 + 滑行器）→ 稳定时间压到 **0.55 s**，但实录最大偏差从 1889 涨到 **4571 ADC**、
  内部事件数 1.6~1.7 倍、用户实测到「过充/下冲」「强扰动下找不到基线」「可重复性下降」。

于是本次调研的问题清单是：

1. 「1~2 s 稳定」在实测数据上究竟如何定义、如何测、能达标多少？（**T1**）
2. 三阶段（阶跃-快相-慢相）的时间特征到底是什么数？（**T2**）
3. 快相爬升**是否稳定**？必须处理它吗？（**T3**——用户明确允许反驳）
4. 零基线起 vs 负载下的两种快相，差多少、怎么分？（**T4**）
5. v6 的过充/下冲、以及 1w±1000ADC 下基线识别不清，能不能靠滤波/判据救？（**T5**）
6. v6 可重复性为什么下降？（**T6**）
7. 卸载/部分卸载的时漂是什么规律？（**T7**）
8. 综合看 v6 面对目标是"能用 / 有条件能用 / 不能用"？（**T8**）
