## 2. CSV 读取规范（**先读这条，能省掉一整轮 debug**）

```text
##Session            ← 元数据块（键值对，行数随通道数变化）
schema_name,...
...                  ← 各录制行数不同
##Data               ← 【数据段标记】
timestamp,elapsed,frame_index,ch0,...,ch20   ← 列名行
<帧数据>
```

**当前 13 份录制的数据列名行都在文件第 25 行**，但**必须自动定位**，不得写死：

```python
import io, numpy as np, pandas as pd

def load_rec(path):
    """自动定位 ##Data，返回 (t, X)；t 用 timestamp 列（禁用 elapsed）。"""
    with open(path, "r", encoding="utf-8", errors="ignore") as f:
        for i, line in enumerate(f):
            if line.startswith("##Data"):
                hdr = i + 1          # 0-based：列名行
                break
        else:
            raise RuntimeError("no ##Data marker in " + path)
    df = pd.read_csv(path, skiprows=hdr)
    ch = [c for c in df.columns if c.startswith("ch")]
    t = df["timestamp"].to_numpy(float)
    return t - t[0], df[ch].to_numpy(float)

def to_grid(t, X, fs=100.0):
    tu = np.arange(0.0, t[-1] - t[0], 1.0 / fs)
    Xu = np.vstack([np.interp(tu, t, X[:, c]) for c in range(X.shape[1])]).T
    return tu, Xu
```

> 既有 `ad_lib.load_rec` 用的是 `skiprows=24`（等价于上面第 25 行），可用；
> 但**新脚本请用自动定位版本**，抗未来格式变化。
