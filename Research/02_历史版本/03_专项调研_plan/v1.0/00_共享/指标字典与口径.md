## 1. 信号与网格

| 记号 | 定义 |
|---|---|
| `X[i, c]` | 第 `i` 帧第 `c` 通道原始读数（ADC 或 `processed_display`，**必须声明域**） |
| `Z[i]` | 帧总量 `Z = Σ_c X[i, c]`（本项目**默认使用总量**做主结论，通道级结论另标） |
| `Z̄` | 平滑量 `Z̄ = median(Z, k)`，`k = round(0.5 s / dt)`；**只用于指标评估，不用于算法输入** |
| `t[i]` | 时间轴，**取 `timestamp` 列**（禁用 `elapsed`） |
| `dt` | 均匀网格步长，**默认 0.01 s（100 Hz）**，用 `np.interp` 重采样 |
| 域 | 恒载 9 组 = `processed_display`；变载实录 4 份 = **ADC**。跨域不可比绝对值 |

> ⚠️ **禁止 τ=2 s 因果指数平滑**。既有「快相 0~4 s 爬升」轮廓就是它的伪影（07-v6 §2.1）。
> 若某分析确需平滑，`k` 不得大于 0.5 s，且必须在报告中声明。

## 2. 事件与阶段

### 2.1 事件定义

| 量 | 定义 |
|---|---|
| **真实加载沿 `t_on`** | 人工标注 / 由 `Z` 的短滞后电平差回溯定位的真沿（**以此为准**），不是检测器触发时刻 |
| **onset** | 空载 → 负载的加载事件（`pre` 电平 ≈ 0） |
| **restep** | 负载内加重/减重事件（`pre` 与 `post` 都在受载电平上） |
| **unload** | 负载 → 空载（**减少量 ≥ 80% 当前电平**） |
| **partial unload** | 负载 → 较低负载（减少量在 20%~80% 之间） |
| **干净事件** | t0 后 8 s、前 3 s 内无其它检出事件；且台阶幅度 ≥ 2% 记录峰值 |
| 台阶幅度 `J` | `J = Z̄(post 窗中位) − Z̄(pre 窗中位)`，`pre` 窗 = `[t0−2, t0)`，`post` 窗 = `[t0+4, t0+6]` |

> `post` 窗取 `t0+4 ~ t0+6` 是**既有口径**（`ad_lib.event_table`），
> 目的是避开快相尾巴；凡与既有数字对比的场合**必须沿用**，若改用别的窗要标注差异。

### 2.2 三阶段（本项目核心对象）

| 阶段 | 起点 | 终点判据 | 主指标 |
|---|---|---|---|
| **S1 阶跃** | `t_on` | 达到 `Z(t_on+τ)` 首次 ≥ `0.5·J` 的时刻 | 单帧跃变比例、`t50` |
| **S2 快相爬升** | S1 末 | 到达 `0.90·J` 的时刻（`t90`） | `t80/t90/t95`、`Z(0.2 s)/J`、`Z(1 s)/J` |
| **S3 慢相爬升** | S2 末 | 记录结束 或 下一次事件 | 慢相速率 `%/s`、`τ_slow`、`t95` |

**边界约定**：快相/慢相的界取 **`t90`**（而不是 `t95`）——理由是 `t95` 在 onset 上被
慢相污染严重；若某分析对边界敏感，**同时给 `t90` 与 `t95` 两套数**。

### 2.3 关键时间指标（对齐既有 `v6_rise_times.csv` 列名）

| 列名 | 定义 |
|---|---|
| `t50/t80/t90/t95` | 从 `t_on` 起算，`Z` 首次达到 `0.50/0.80/0.90/0.95·J` |
| `z_at_02` | `(Z(t_on+0.2) − Z(t_on)) / J` |
| `z_at_10` | `(Z(t_on+1.0) − Z(t_on)) / J` |
| `pre / post / jump / ratio` | 见 §2.1；`ratio = |J| / max(pre, 1)` |

## 3. 稳定与鲁棒性指标（T1 负责冻结，其余任务引用）

| 指标 | 定义 | 备注 |
|---|---|---|
| **T_stable（本项目主指标）** | 从 `t_on` 到**显示读数首次停住**的时间：即存在 `τ`，使 `t ≥ t_on+τ` 后 30 s 内自身漂移 ≤ **5%·J**，且不再出现同向移动 | 与 07-v6 的 `T_stable` 同义（"首次停下、此后 30 s 漂移 ≤5%×阶跃"） |
| **T_settle(ε)** | 首次进入并保持 `|Z(t) − Z_final| ≤ ε·J` 的时间，`ε ∈ {2%, 5%}`；`Z_final` = `t_on+60 s` 后的中位 | ε 必须写明 |
| **超调 OS%** | `max_t (Z(t) − Z_final) / J`（`t ∈ [t_on, t_on+30 s]`），负值表示下冲（**欠冲 US%** = 最小值的绝对值） | v6 过充问题的核心量 |
| **残差时漂 D%** | 慢相窗内 `(尾部 1/5 均值 − 首部 1/5 均值) / 电平` | 对齐既有 `slow_windows` 口径 |
| **台阶捕获比 G** | 事件后 20 s 内「显示增量 / 原始增量」 | 1.0 = 台阶完整透传；既有 v5 = 0.98 |
| **最大偏差 MD** | 在指定窗内 `max |显示总量 − 原始总量|`（**绝对 ADC**，与电平一起报） | 既有 v6 = 4571 ADC 用的就是它 |
| **epoch 数** | 补偿器内部新建事件次数 / 每 100 s | 反映状态机抖动 |
| **误触发率 FPR** | 非真实加载事件（拍击/噪声/抖动）导致的内部事件数 ÷ 扰动注入次数 | T5 的鲁棒性指标 |
| **重捕获延迟** | 真实事件 `t_on` 到补偿器建立正确基线的滞后 | T5 的"找不到基线"量化 |

> **T1 未冻结前**，其余任务可先用本表定义开工，但**必须**在 T1 交付后核对一次并在报告中注明是否一致。

## 4. 可重复性指标（T3 / T6 共用，**必须严格同口径**）

| 指标 | 定义 |
|---|---|
| **CV_shape(τ)** | 归一化形状 `f(τ) = (Z(t_on+τ) − Z(t_on))/J` 的**跨事件变异系数** `std/mean`，按 τ 网格报（0.05~5 s） |
| **Spread(τ)** | 同上但报 `p10~p90` 区间（对 n 小更稳），**默认报这个** |
| **k_shape** | 用一族归一化形状拟合各次加载得到的形状参数（如 τ_f），报其 `CV` |
| **重载偏差 Δ_rep** | 同一载荷"加压→卸载→再加压"时，两次 `Z_final` 之差 ÷ 载荷 |
| **冻结偏差 Δ_frozen** | 卸载后补偿器残留偏移 ÷ 原载荷（T7 定义，T6 引用） |
| **路径抖动** | 同一数据、同一算法、只改输入量化/抖动（±1 包时序、±σ 噪声）时输出轨线的 RMS 差 |

## 5. 曲线与扰动（T1 提供注入器，T5 使用）

| 项 | 定义 |
|---|---|
| 阶跃插值 | 余弦半波上升沿，`rise_ms` 默认 50 ms |
| 拍击 tap | 上升 `rise_ms` + 保持 `hold_ms` + 回落 `fall_ms`（默认 50/100/50 ms），峰值 = `amp` |
| 带限噪声 | FFT 置零窗外的带限随机序列（默认 `[0.3, 40] Hz`），**总量 RMS = A（ADC）** |
| 扰动幅度口径 | **一律以"总量扰动的 RMS 或峰值"标注**，不要用单通道幅度 |

> **复制到本任务 `scripts/` 内改名 `t<N>_common.py`**（不得直接 import 既有桶，也不得修改它）。

## 6. 单位与报数规范

1. **ADC 与 %**：绝对量用 ADC，相对量用 %，**同时给出**绝对与相对（如"4571 ADC（约 29% 电平）"）；
2. **中位数优先**：n < 20 时报**中位 + p10~p90**，不报 mean±std；
3. **有效数字**：时间到 0.01 s，百分比到 0.1%，ADC 到整数；
4. **样本量必须写**（n=9 / n=15 / n=4 份录制…），n ≤ 3 时明确标"仅作定性参考"；
5. **不确定度**：凡结论落在包时间戳量化（指尖 16.7 ms / 实录 40 ms）量级内，
   必须给 ±1 包敏感性；落在 0.2 s 以内的结论一律标注"处于时间轴畸变区"。
