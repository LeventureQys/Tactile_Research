# T4 需求文档 —— 两种快相形态（零基线起 / 负载下）的对比与分支判据

| 项 | 值 |
|---|---|
| 任务 ID | **T4** |
| 回答用户诉求 | ④「有关这个快相爬升，其还有两种形态，分别是从零基线开始的快相爬升，以及在负载的情况下快相爬升，这两种情况的快相爬升速度和幅度都不太一样，所以也请你思考一下」 |
| 依赖 | T2（形状剖面）、T3（可重复性结论 —— **T4 必须知道"形状是否稳定"才能谈"是否需要分两支"**） |
| 席位 | **2 个 SubAgent**（A：形态表征与机制；B：分支判据设计与误判率评估） |
| 模型 | deepseek / deepseek-v4-flash |
| 预期耗时 | 30~50 min |

---

## 1. 任务目标

把用户的观察（"两种快相速度幅度都不一样"）**量化**，并且**判定到底该不该分成两支**：

- 如果两形态的差异**可以用一个连续量描述**（例如"输入斜坡时长"），那么**不需要**硬分支，
  用参数化/自适应即可；硬分支反而会引入**切换抖动**（v6 的 epoch 数暴涨可能就是分支抖动的代价）；
- 如果两形态是**质的差别**（不同物理机制、不同参数族），才需要分支。

所以 T4 的**核心交付不是"造一个分类器"，而是"判定分类是否必要 + 若必要，最简判据是什么"**。

---

## 2. 必须回答的子问题

### T4-A（形态与机制）

| # | 子问题 | 期望输出 |
|---|---|---|
| T4-Q1 | 两形态的**特征表**：`t50/t80/t90/t95`、`z_at_02`、`z_at_10`、台阶幅度、上升沿数、指数/幂律参数、上升沿"单帧跃变占比" | `t4_morphology.csv`（每事件一行，带 `armed` 标志：空载起 or 带载起） |
| T4-Q2 | 两形态的差异**有多大**（效应量，不只是 p 值）：中位差、`p10~p90` 重叠度、可分性指标（如 AUC） | 差异量化表 |
| T4-Q3 | 机制是什么？**"差异在输入而非传感器"**这一既有论断（07-v6 §2.2）能否被独立验证？给出证据： | 机制证据（至少 2 条独立证据） |
| T4-Q4 | 是否存在**中间态**？即"半载上加压""被手拍击后的加压"等，是否落在两形态之间的连续谱上？ | 中间态样本表 + 连续谱图 |

### T4-B（分支判据）

| # | 子问题 | 期望输出 |
|---|---|---|
| T4-Q5 | 若需要分支，**最简判据**是什么？候选：① `pre` 电平门限（是否带载）；② 上升沿时长（输入斜率）；③ 台阶幅度相对电平比；④ 上升沿形状（单帧跃变 vs 多帧斜坡）。**只允许用因果可得信息**（不许用未来帧） | 候选判据表 + 各自可分性 |
| T4-Q6 | 判据的**混淆矩阵与误判代价**：把 onset 误判为 restep（或反之）时，最终 `T_stable`/超调/最大偏差会差多少？ | `t4_branch_confusion.csv` + **误判代价表** |
| T4-Q7 | **该不该分支**的裁决：用"连续参数化（不分支）"与"硬分支"两种做法在同一批事件上的表现对比 | 裁决 + 数字（**允许结论是"不要分支"**） |
| T4-Q8 | 若分支，**切换抖动**有多大？同一段数据在门限附近的输入抖动下，会不会反复切换（chattering）？给迟滞设计的必要性与参数 | 抖动敏感性 + 迟滞参数建议 |
| T4-Q9 | **跨载荷量级**：数据里有没有不同载荷量级的加载？（若没有，明确写"无数据，无法判定量级依赖性"，并给出需要补采的规格） | 缺口声明 + 补采规格建议 |

## 3. 方法与实现要求

1. **`armed` 标志的判定口径必须写清**：例如"`pre` 窗（`t0−2~t0`）中位电平 ≥ 20% 记录峰值 ⇒ 带载起"。
   用多个门限（10%/20%/30%）做敏感性，避免结论挂在单门限上。
2. **因果性检查**：T4-Q5 的判据只能用 `t ≤ t_on + Δ` 的信息（Δ 必须写明，且 Δ 越小越好）。
   若某判据需要 1 s 数据才能分辨，那它对"1 s 稳定"目标**没用**——必须明确指出。
3. **误判代价用 T1 的指标**表达（`T_stable`、超调、最大偏差），不要用抽象损失。
4. **允许 T4 推翻 T3 的分支前提**：如果 T3 认定"形状不稳定、不宜用固定形状库"，
   T4 的分支判据设计要相应调整（例如改为自适应），并在报告里说明这种依赖关系。
5. **图**：至少 3 张——① `T4_01_two_morphology.png`（两形态归一化轮廓 + 变异带）；
   ② `T4_02_separability.png`（判据特征空间散点/ROC）；③ `T4_03_branch_cost.png`（误判代价）。

## 4. 验收标准

- [ ] T4-Q1~Q9 全部有答案 + 数字 + `results/` 指向；
- [ ] 两形态差异给出**效应量**（中位差 + 重叠度 + AUC），不是"显著不同"；
- [ ] 机制论断"差异在输入不在传感器"给出**至少 2 条独立证据**（或明确推翻）；
- [ ] 判据候选**全部是因果可得的**，并标注每个判据所需的数据窗长度；
- [ ] 给出**"是否分支"的明确裁决** + 若分支则给迟滞设计；若不分支则给连续参数化方案；
- [ ] 误判代价表用 T1 指标表达；
- [ ] 数据缺口（跨载荷量级）明确声明 + 补采规格；
- [ ] 报告含「与既有结论的差异」：逐条对照 `07-v6` §0.2 的 onset/restep 表、
      `13-v6-assessment/results/fastphase_profiles.csv` 与 `shape_*.csv`。

## 5. 已知陷阱

1. **把"两形态"当成"两类工况标签"就完事** → 用户要的是**能不能据此做算法**，
   所以必须走到"判据 + 误判代价 + 该不该分支"。
2. **用非因果判据**（如用整个事件的 t90 来分类）→ 那是事后标注，不是可实现的判据。
3. **样本不平衡**：onset（n≈9）远少于 restep（n≈15），算 AUC/混淆矩阵时要说清，
   不要把"多数类全猜对"当成好判据。
4. **忽略"卸载"这第三种形态** → 卸载段的时漂规律是 T7 的活，但 T4 在分类时应把卸载事件
   排除或单列，否则会污染 restep 的统计。
5. **把拍击（手拍）当成第三种快相形态** → 拍击是 T5 的扰动分析对象，物理机制不同（无持续载荷），
   若 T4 里出现，必须单独标注并说明为何不并入分类。
