# plan v3.2 · 问题清单与改动说明

> 本轮主题：**R1「重载蠕变接力」——修掉「完全卸载 → 重载后显示补偿归零」**。
> 定因不是"没拿到阶跃"，而是**交接锚定把已长出的蠕变当成无蠕变电平**。
> 交付形态：`src_v32/` 下的候选源码（由 `scripts/make_v32_variant.py` 从 `src/` 生成，**产品源码未改**）
> + 离线回放 A/B + 总波形效果图。**未做真机 A/B、未改产品代码、未写单元测试。**

## 2. 定因（一条，链条清楚）

`Handoff()` 的

```cpp
A_new = y0 + share·Â        // 无蠕变电平 = 交接时刻的显示电平 + 形状反演增量
```

隐含前提是「**交接时刻的显示 = 无蠕变电平**」。首次加载时该前提成立（显示还停在快相平台，
远低于最终平台）；**完全卸载后重载时不成立**——交接时刻的显示已经是平台的慢相电平。

| | 首次加载（3.30 s） | 重载（245.27 s） |
|---|---|---|
| 交接帧 | 6.83 s | 248.78 s |
| 交接后锚定 `A_sum` | 12 068 | **17 048** |
| 交接当帧输入 | 12 645 | 17 007 |
| 该次加载最终平台 | 17 523 | 17 536 |
| **慢相余量 = 平台 − A** | **+5 454** | **+488** |
| 后段补偿 | +1 881 | **−84** |

机制：`g_raw = median((v_i − A_i)/A_i) ≈ 0` ⇒ rank-1 扣除 ≈ 0、PCT 被地板钳住 ⇒ 补偿恒 0
且**永不恢复**（此后所有卸载-重载沿都复现）。

触发链：240.11 s 完全卸载（Δin −15020，读数回到 2596）→ C4 走 `ToIdle()`，
epoch 与 `g` 清掉 → 245.27 s 重载以新 onset 起跳 → 快相被正确跟随到平台 →
交接把 `A` 钉在平台上 → 基线丢失。

> 与既有登记缺陷**不是同一件事**：文档 §9.1 说的「大偏置＋小增量使 `idle_now` 退化」在本录制
> 不成立（空载基线 2573、判据工作正常）。这是**新失效模式**。

## 3. 改法（R1，两条配套 + 一条连续化）

物理前提：**蠕变是粘弹性响应，不会因为读数为零就消失**；短时卸载只部分恢复。
因此「这个负载已经长出多少比例的蠕变」应当是**会话级状态**，而不是 epoch 级状态。

1. **会话级蠕变比记忆 `creep_ratio_`**（新增，跨卸载保留）
   - 慢相每帧：`creep_ratio_ += (dt/30 s)·(总扣除 / ΣA − creep_ratio_)`（只在"确有扣除"时更新）；
   - 空载期：向 0 **按 τ=45 s 衰减**（近似部分恢复；本录制卸载间隙 4.5 s ⇒ 只衰减 ≈10%）；
   - 卸载前一刻的瞬时值记入 `prev_creep_`，衰减由它出发（避免卸载瞬间被 0 拉平）。

2. **重载时注入蠕变种子**（只对「从 Idle 起跳的 Onset」，即真实卸载后的重载）
   - `seed = creep_seed_gain · creep_ratio_ · inc_max`（用**实测电平增量** `inc_max` 作分母，
     不用 `Â`：`Â` 在交接前已收敛到 1.05~1.12×inc，而 `inc_max` 单调、无形状先验）；
   - 事件期按 **w = clamp(2·inc_s / inc_max, 0, 1)** 渐入（与实测上升同步 ⇒ 与滑行修正同源、天然连续）；
   - 交接时 `A_new = y0 + share·(Â − seed)`：把已长出的蠕变从"无蠕变电平"里扣掉，
     余量还给慢相，`g_raw` 才不会归零；
   - 交接时把 `seed` 写进 `pct_ded_`（分配向量与事件期完全一致）⇒ 交接处严格连续、无跳变。

3. **冷启动逐位不变**：`creep_ratio_start = 0` ⇒ 首次加载 `seed = 0`，
   `gain` 从 0 到 1.0 的 A/B 里**首列完全相同**（1621 / 1685 / 1986 / 2195），即首次加载行为未变。

## 4. A/B 结果（同一录制、同一回放口径，`results/v32_gain_ab.txt`）

## 5. 未关闭 / 已知边界（必须与结论同读）

| # | 事项 | 状态 |
|---|---|---|
| 1 | **261.7 s / 289.3 s 那两次重载仍拿不到补偿**（−50 / −） | **未解决**。它们是**短保压后的部分卸载-重载**：卸载瞬间 `creep_ratio_` 还很小、空载期又按 45 s 衰减 ⇒ 种子太小。属"同一次保压内的负载调整"，与"整段卸载后再加载"物理不同，需要单独口径。 |
