## 2. K10 —— e 残差反馈

`K10_e残差反馈/K10_e残差反馈.md`｜脚本 `scripts/k10_eval.py`｜图 `figures/`（11 会话的 K9 vs K10 对照 + `k10_all_sessions_summary.png`）

**机制**：`e_now = y − x1 − x2` 是弹性残差，其导数 `de/dt` = 显示残余漂移率。
K9 及之前全部是**前馈**（从 y 的导数推状态）；K10 增加**闭环**：`de/dt` 经 τ=2 s 低通后按 `fb_gain`
反馈进 x2 积分率（clip ±cap，仅 `slow_confirm` 之后启用）。

**实测（11 会话）**：

| 会话 | 收敛 K9→K10 | 残余漂移 K9→K10(k=1.0) | 空载 K9→K10 |
|---|---|---|---|
| efd432 轻载长保压 | **134.9 s → 1.2 s** | −0.72 → −1.20 | −0.25 → −0.34 |
| 3f32c5 | 7.7 s → **1.2 s** | −1.65 → −3.19 | 0 → 0 |
| 73032d | 3.3 s → **1.5 s** | −3.37/−2.03 → −4.26/−3.16 | −651 → −699 |
| 9c3ca5 | 35.2 s → 35.1 s | −3.86 → −5.51 | 0 → 0 |
| 86eca9 / 2e35b8 / 其余 | 不变 | 近似不变 | ≈不变 |

**四条结论**：

1. **收敛速度大幅改善**：轻载/中载长保压的表观收敛从 135 s / 7.7 s 降到 ~1.2 s；
2. **代价是过补偿**：残余变负（补偿越过蠕变率），把"上漂"换成了"缓慢下沉"；
3. **k=0.5 与 k=1.0 过冲相近** ⇒ 环路滞后（`fb_tau=2 s`）主导，不是增益问题 ⇒ **"调小增益"这条路排除**；
4. 空载保护不受损（除 73032d −651 → −699 轻微）。

**健康判据（第二轮纠正了自己上一轮的误判）**：`bias_last` **不是**过冲量；
真正判据是**残余斜率 vs 蠕变率**——残余 = −蠕变率 ⇒ 显示持平（理想）；比它更负 ⇒ 病理过冲。

| 会话 | 蠕变率 | K10 残余 | 判定 |
|---|---|---|---|
| efd432 | +1.21 | −1.20 | **理想**（显示持平；K9 的 −0.72 是欠补） |
| 3f32c5 | +1.44 | −3.19 | **病理过冲**（显示 −1.75/s 下沉） |
| 9c3ca5 | +7.85 | −5.50 | 仍欠补 70%（改善） |

**根因（逐项排除后锁定）**：fb 单向（`clip ≥ 0`）且 x2 受载期**无回吐路径**
⇒ 加载瞬态冲进去的超额补偿被**永久锁死**，显示从此恒定多扣。
双向 fb（负 `lp_de` 回吐）实验：3f32c5 −3.19 → −1.67（病理过冲消失），
但 efd432 −1.20 → −0.72（理想跟踪同时消失——负半周抵消了正半周驱动）。

**最终设计方向（待做）**：**带死区的双向 fb**——`lp_de > 0` 全额正反馈（保留欠补驱动），
`lp_de < −threshold` 才回吐（解除锁死超额），threshold 取蠕变噪声尺度。
配合轻载标定录制整定后入 C++。**C++ 保持 K9。**

## 3. K8 —— 轻载残余上漂（未定位）

`K8_轻载残余上漂/K8诊断与优化尝试.md`｜脚本 `scripts/{k8_probe,k8_eval,deadband_sweep,gate_floor_sweep,onset_study}.py`

**现象**：K7 输出在 x1 段结束后仍缓慢上漂，且**只发生在轻载/低电平段**（重载段已完全跟平）。

| 会话 | pre 平台蠕变率 | K7 残余漂移（同窗口径） | 补偿率 |
|---|---|---|---|
| efd432 轻载长保压（总值≈550，重载的 4%） | +1.21 ADC/s | −0.72 | ~60% |
| 9c3ca5 | +7.85 | −3.74 | ~48% |
| 3f32c5 重载保压 | +1.44 | −1.65 | ~100%（已平） |
| 73032d | +13.26 | −3.46 | — |

**六个假设全部证伪**（参数扫过、数据不动）：

| # | 假设 | 结果 |
|---|---|---|
| 1 | x1 不够激进（r1→0.15、τc1→8、eps 2→6） | 漂移率 **+0.49 纹丝不动** |
| 2 | 零点闪烁拖拽（`zero_confirm_s=2s`） | +0.49 → +0.43，次要 |
| 3 | x2 泄放被闪烁放血（`discharge_confirm_s=2s`） | 无感 |
| 4 | 旁路全通道空载化（`bypass_all_idle`） | 漂移 +0.43 但**空载保护灾难性回退**（efd432 −0.25→−233）⇒ **已否决，禁止入 C++** |
| 5 | 旁路死区收窄 / 慢态积分门绝对下限 / idle 确认窗 2→10 s | 全部零变化 |
| 6 | 受载记忆锁、x1 受载期慢泄放 | 全部零变化 |

**当前最可信的解释**：轻载平台的残余上漂是 **K7 设计取舍的固有代价的叠加**——
① 轻载总值落在总值旁路死区内（< 1.15×基线）时按设计直通，原始蠕变穿透；
② 死区边缘 total 在 release 门限附近抖动，直通/补偿交替，等效漂移为两者按占比 mix；
③ 逐通道机制在轻载下 idle 门限与残差同量级，零点/泄放轻微漏血。
绝对量级：0.43 ADC/s ≈ 满量程（12700）的 0.2 %/min，且重载工况为 0。

**结论**：**参数空间已穷尽，残余上漂只能结构改。** C++ 维持 K7。
下一步方向（未做）：按通道 bypass（判据从"总值 vs 基线"改为"逐通道 vs 自身包络"）、
或在线辨识份额上限（`r_fast` 不再固定）。**前置数据需求**：补录
**已知轻载（5 % / 10 % / 20 % 满量程砝码）恒压 10 min** 的标定会话。

> **附带产出（对 K9 有直接价值）**：`K8诊断与优化尝试.md` §5 定量证实了
> **"起步过充与收敛速度相关"**：过充比 ≥1.0（快上冲）⇒ 25 个平台全部 0.1~6 s 收敛；
> 过充比 ≤0.9（缓坡渐加载）⇒ 8~135 s。这正是 **K9 缓坡前馈的立项依据**。

## 4. x1 形状与回落 —— 三路并行研究

入口：**`x1形状与回落/x1_shape_study/综合结论与优化方向.md`（先读这个）**
原始工作说明：`x1形状与回落/plan_v4_README（原始）.md`（路径里引用的 `progress/currentworking/算法说明_v3.4观测器.md`

| 子目录 | 内容 |

| `x1_shape_study/T2_adaptive/` | **自适应形状**：报告 `T2_自适应形状报告.md`（39 KB）+ 14 脚本 + 10 结果 + 6 图 |
| `x1_shape_study/T3_feedforward/` | **前馈研究**：报告 `T3_前馈报告.md`（24 KB）+ 16 脚本 + 20 结果 + 5 图 |

| `fall_study/` | **阶跃后"峰后回落过大"专项**：归因 + E/F 修正变体（`回落研究报告.md`） |

### 4.1 核心结论（**归因与直觉相反**）

| 工况 | 回落主因 |
|---|---|
| **受载态小台阶**（用户主诉场景） | **x2 占 75~85%**（沿后过积分，以 2.5~5.7 倍于真实斜率的速率吸收输入爬升）；x1 仅 15~25% |
| 首次从零大加载 | x1 占主（~58%），但绝对量仅 1.4~2.4 %·台阶 |

三个研究问题的答案：

1. **形状**：实测快相不是纯单指数（等效 τ 随窗口 9.7→14 s；= 快分量 10~12 %/τ≈2 s + 主慢分量 τ≈25 s），
   但与固定形状的偏差逐通道中位只有 **5~7 ADC**，比 300~520 ADC 的回落小一个数量级；
   且模型 τc1=8 s 比实测**快 20%**（对齐方向应是**调大** τ）。
2. **形状-e 绑定**：**数据不支持**——形状参数与台阶幅度无相关（ρ=−0.07）；强相关的是**幅度比例**（ρ=−0.688）：
   实测结构 =「≈30~40 ADC 常数 + 3~5 %·e 比例」，而模型是纯比例 `r1·e`（小台阶恒欠扣、大台阶恒过扣）。
   自适应实现在架构约束内**不可行**（幅度自举锁死 / τ 自适应噪声级 / 形状自适应方向反）。
3. **前馈**：F-B（沿后 1~2 s τ_boost）可消除首次大台阶过扣下冲（max 1246→410 ADC）、误触发无害；
   但**稳定时间降不到 2~4 s——天花板被 x2 压死**。

### 4.2 优化方向（按优先级，**待拍板**）

1. **改常数**：τc1 8→32（或 r1→0.08 + τc1→32），低风险；
2. **T4（建议主攻）：x2 沿后行为**——沿后短窗冻结/降权 x2 积分、调小 τ_slope、收紧沿门放开速度；
   目标小台阶回落 600 → **<100 ADC**；
3. 回落是硬指标时：**B_bi2 双速率并联 x1**（回落可清零，代价保压 std **+45%**）；
4. F-B 前馈可与 ① 叠加；
5. 可选：x1 幅度先验改「常数 + 小比例」结构；
6. **不做**：形状-e 绑定、V-A/V-C 自适应、F-A lag 前馈、为治回落调小 τc1。

### 4.3 研究纪律与已知边界

- 全部结论来自**离线回放**（纯 Python），**未做真机 A/B**；改 C++ 前须先原型验证并全量回放；
- 回放 parity 只在部分会话达标（录制起点算法状态 ≠ 零），反事实归因限定在低 parity 事件子集；
- 数据面两个坑：`elapsed` 列 ~70 % 帧重复，须按 100.5 Hz 重建均匀时间轴；
  录制显示流有单帧尖峰，峰值类指标先做 0.3 s 中值滤波。

## 6. 维护本层的约定

1. **每条结论都要能被检验**：写清"验证了几组数据 / 口径是什么 / 结论 / 为什么没进 C++"。
2. **失败也是结论**：K8 的六条证伪假设、K10 的"调小增益路线排除"都是有效产出，**不要删**。
3. **口径必须连数字一起写**：同一批数据在不同 E 口径下落点能差 2.7 N（见
   `../01_当前工作_K9/02_现场调参/09-26_09-27_工程B_手掌/手掌_力值模式_8参数终版与代价.md` §八）。
4. **进了 C++ 就搬家**：课题一旦落地到 `src/`，把它的结论整包移入 `../01_当前工作_K9/`，本层只留"为什么这么设计"的指针。
5. **不要在本层写"已实装"**——除非你刚刚核对过 `src/` 并在此写明核对方式与时间（K11 就是反例）。
