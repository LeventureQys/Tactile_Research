## 1. 我们在做什么

v2.7 版本的核心课题是**抗蠕变补偿**：传感器恒压加载后读数会持续上爬（快相 5~30 s +
慢相 ≥100 s），要求加载后 1~2 s 稳定。当前产品实现是 **v3.4 在线双态蠕变观测器**
（`src/domain/drift_v6/creep_observer.{h,cpp}`）：逐通道维护零点跟踪 + 快态 x1 +
慢态 x2，显示 = v − x1 − x2，其中 e = max(y−x1−x2, 0) 是弹性响应估计。

本 session 的切入点是用户的一个现场观察与假设：

> **拿到 e 之后，x1 的补偿导致显示数值回落过大。** x1 的形状是固定的（单指数、
> 幅度 r1·e、τc1=8 s），怀疑与传感器真实快相蠕变的形状对不上。

由此组织了三个递进的研究问题，并行派发 SubAgent 用真实录制数据做离线回放研究：

1. **T1 形状研究**：实测快相蠕变到底什么形状？与固定 `1−exp(−t/8)` 差多少？
2. **T2 形状-e 绑定**：x1 的形状/幅度能不能不固定，改成跟随 e 的形态自适应？
3. **T3 提前补偿**：沿检测 + 前馈置位 x1，能不能"提前补偿"，改善回落与稳定时间？

## 3. 核心结论（详见《综合结论与优化方向.md》）

**回落是真的，但归因和直觉相反**：

| 工况 | 回落主因 |
|---|---|
| 受载态小台阶（用户主诉场景） | **x2 占 75~85%**（沿后过积分，以 2.5~5.7 倍于真实斜率的速率吸收输入爬升）；x1 仅 15~25% |
| 首次从零大加载 | x1 占主（~58%），但绝对量仅 1.4~2.4%·台阶 |

三个研究问题的答案：

1. **形状**：实测快相不是纯单指数（等效 τ 随窗口 9.7→14 s；= 快分量 10~12%/τ≈2 s +
   主慢分量 τ≈25 s），但与固定形状的偏差逐通道中位只有 **5~7 ADC**，比 300~520 ADC
   的回落小一个数量级；且模型 τc1=8 s 比实测**快 20%**（对齐方向应是调大 τ）。
2. **形状-e 绑定**：**数据不支持**——形状参数与台阶幅度无相关（ρ=−0.07）；强相关的
   是幅度比例（ρ=−0.688）：实测结构 =「≈30~40 ADC 常数 + 3~5%·e 比例」，而模型是
   纯比例 r1·e（小台阶恒欠扣、大台阶恒过扣）。自适应实现在架构约束内不可行
   （幅度自举锁死 / τ 自适应噪声级 / 形状自适应方向反）。
3. **前馈**：F-B（沿后 1~2 s τ_boost）可消除首次大台阶过扣下冲（max 1246→410 ADC）、
   误触发无害；但稳定时间降不到 2~4 s——天花板被 x2 压死。

## 4. 优化方向（按优先级，待拍板）

1. 改常数：τc1 8→32（或 r1→0.08 + τc1→32），低风险；
2. **T4（建议主攻）：x2 沿后行为**——沿后短窗冻结/降权 x2 积分、调小 τ_slope、
   收紧沿门放开速度；目标小台阶回落 600→<100 ADC；
3. 回落是硬指标时：B_bi2 双速率并联 x1（回落可清零，代价保压 std +45%）；
4. F-B 前馈可与 ① 叠加；
5. 可选：x1 幅度先验改「常数 + 小比例」结构；
6. **不做**：形状-e 绑定、V-A/V-C 自适应、F-A lag 前馈、为治回落调小 τc1。

## 5. 研究纪律与已知边界

- 全部结论来自离线回放（纯 Python），未做真机 A/B；改 C++ 前须先原型验证并全量回放；
- 回放 parity 只在部分会话达标（录制起点算法状态≠零），反事实归因限定在低 parity
  事件子集；
- 数据面两个坑（写脚本必知）：`elapsed` 列 ~70% 帧重复，须按 100.5 Hz 重建均匀时间轴；
  录制显示流有单帧尖峰，峰值类指标先做 0.3 s 中值滤波；
