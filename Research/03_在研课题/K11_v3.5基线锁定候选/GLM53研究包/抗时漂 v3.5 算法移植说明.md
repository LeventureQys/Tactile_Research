# 抗时漂 v3.5（K10/K11）算法移植说明（嵌入式端）

> v3.5 = v3.4 观测器（27 参数，见《抗时漂 v3.4 算法代码说明与移植指南.md》）**原样保留**
> ＋ 两个默认关闭的叠加结构：K10 `track_base_frac`、K11 `hold_lock_tau_s/hold_lock_freeze_s`。
> 上位机权威实现：`src/domain/drift_v6/creep_observer.{h,cpp}`（与本文同步）。
> 上位机已内置「v3.5 基线锁定」菜单档（录制 manifest id=`drift_v35_hold_lock`、
> param_set=`plan-v3.5 k10-k11`），参数对话框 12 项可调 + K10/K11 两个开关（取消勾选即
> 系数置 0，完全回退 v3.4 逐帧行为）。

## 1. 相对 v3.4 的全部增量

| 项 | 内容 |
|---|---|
| 参数（3 个，默认 0=关闭） | `track_base_frac`（K10，x2 基数系数）；`hold_lock_tau_s`、`hold_lock_freeze_s`（K11，锁定 τ / 沿后冻结窗）。全参数共 30 项（27+3） |
| 状态（每通道 2 个） | `lock_lp`（基线锁定低通，初值 0）；`t_lock`（距上次上行沿时长，初值 1e6） |
| 改动点 | ① x2 分支内 base 计算（K10）；② 通道循环末尾新增 K11 更新；③ 输出额外扣 lock_lp |
| `edge_slope_thres` 语义扩展 | 该参数属于 v3.4 原有 27 项，v3.5 中同时充当 **K11 快/慢变分类阈**：上行超阈=沿（触发冻结）、下行超阈=快卸载（瞬时跟随）。上位机已将其暴露为第 12 个 UI 可调项 |
| 关闭时行为 | 与 v3.4 **逐帧完全一致**（等价性验证 err_end 完全相同） |

## 2. 逐帧伪码（增量部分，接在 v3.4 §6 伪码的 ⑨ 之后）

```
⑧-x2 分支内（K10，仅一行变化）：
    base = max(e, 1.0)
    if track_base_frac > 0:  base = max(base, track_base_frac * y_max[k])   # y_max=v3.4 包络

⑩-K11（通道循环末尾，hold_lock_tau_s>0 时）：
    t_lock[k] += dt
    if slope[k] >  edge_thres: t_lock[k] = 0            # 仅上行沿触发冻结
    down = (y[k] < lock_lp[k])
    if down:
        if slope[k] < -edge_thres:  lock_lp[k] = y[k]   # 快卸载：瞬时跟随（防下冲）
        else: lock_lp[k] += dt/(tau*0.25) * (y[k]-lock_lp[k])   # 慢下行 4 倍速
    elif t_lock[k] >= freeze_s:
        lock_lp[k] += dt/tau * (y[k]-lock_lp[k])        # 上行慢跟随（扣蠕变）
    # 冻结窗内上行不跟（真实快加载直通显示）

⑪-输出：
    display = v − (hold_eps>0 ? applied : x1+x2) − lock_lp
```

## 3. 定点/嵌入式注意

1. `lock_lp` 幅度可达通道满量程，定点建议 Q15/Q31 同 v3.4 的 x1/x2；`t_lock` 用 32 位 ms 累加即可。
2. 快卸载瞬时跟随（`lock_lp = y`）是直通赋值，无除法/除零风险；`dt/tau` 与 `dt/(tau*0.25)` 建议查表或倒 数预计算（τ 参数固定时）。
3. K10 只改一处乘加；K11 每通道每帧 1 次比较 + 1 次一阶低通，RAM 增量 = 2×n_ch×字宽 + 2×n_ch×(t_lock)。
4. K11 与 K6 预留池可共存（display 额外减 lock_lp），但 v3.5 预设建议 hold_eps=0（纯锁定）。
5. 验收：① hold_lock_tau_s=0 时逐帧对拍 v3.4（应零差异）；② 恒载保压 0~3s 入带、±150 ADC 带内；③ 快卸载（>edge_thres 下行）显示无持续下冲；④ 反复荷载空隙基线逐周期回零（无棘轮）。

## 4. 语义边界（务必写进设备手册）

- K11 把**慢于 τ 的上行一律当蠕变扣除**（含真实慢加载）；快加载（沿）在 freeze 窗内直通、之后衰减回 0。适合「装好负载→调零→盯保压/报警」的用法。
- 需要显示持续载荷/慢变载荷的场合保持 `hold_lock_tau_s=0`（即回退 v3.4 行为，可用 K10 改善 x2 跟随）。
- K11 与 v3.4 的 x1/x2/K6 可共存，但 v3.5 预设将 x 支路置空挡（r_fast=0、slope_gate_frac=0.001、r_slow_max=0、hold_eps=0）——机理上仍每帧执行、状态保持 ≈0，**不是删除**；嵌入式按同样方式保留全部 v3.4 代码路径，只改参数即可在两种行为间切换。

### 5.3 微调口诀

上漂收不住 → τ 减小（手掌 0.8→0.5→0.3）；波动被削多 → τ 加大；快加载想多显示一会儿 →
freeze 加大；快卸载瞬态下陷 → edge_slope_thres 调小（更快判为快卸载、瞬时跟随）。
τ 口径：蠕变越快 τ 越小（拇指快分量 τ1≈4s → 0.15s；手掌 τ1≈9s → 0.8s）；带宽 ≈ 蠕变速率×τ。
