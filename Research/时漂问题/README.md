  **K7**（受载确认 + 去趋势空载门 + 全局总值旁路，修"循环加载棘轮 / 空载塌陷"）→
  **K9**（缓坡前馈，补"缓坡加载不触发沿"的收敛盲区）。
- **K9 是最后一层**，共 27 个参数；其中 **8 个**经 UI 暴露并可下发设备寄存器 **200~208**。
- **2026-09-27 已产出首件参数表**（4 类传感器分档）→ `01_当前工作_K9/02_现场调参/09-27_首件参数列表/`。
- ⚠️ **两条必须先知道的不一致**（详见 §7）：`GLM53/抗时漂 v3.5 算法移植说明.md` 声称的
  「v3.5 / K10 / K11 已内置菜单档」**在当前源码树中并不存在**；`plan/v4/k9` 引用的
  `抗时漂 v3.4 抗下漂变体设计（草案D1）.md` **全树找不到**。
- **2026-10-14 进度**：K9 本体未改。新增 **K10 = 瞬态防护**（`02_K10_...`）：
  已定性定位"短促下探 → `y_floor` 触底 → idle 快泄放 → 补偿量永久减少、基线被顶高"这一链路，
  并给出默认关闭的防护（实测污染从 +24 ADC 降到 −0.05 ADC，长期稳态差 0）。
  同批产出单文件可移植交付（`03_K10_...`，与 K9 逐帧差 0.0）。**均未下发固件。**
- **2026-10-19 进度**：定位到 **K9/K10 共有的长恒载缺陷**并给出修复（`05_阶梯上飘诊断_20261019/`）：
  `y_floor` 的**抬升**分支无条件执行，26 min（≈5τ）后追平 `y0`、把载荷吸收进基线；
  随后 idle 判据被单帧噪声击穿 → `zero` 以 τ=8 s 吞掉载荷 → `x_slow` 按 0.2 s 泄放归零 →
  逐通道接续崩塌，总力呈**阶梯状上飘**。48 min 实录：输入只漂 +314 ADC，输出漂 +3494 ADC（11 倍）。
  **K10 防护层拦不住**（它只守下行与快泄放），同数据末态 applied 仅 3.4 ADC（比 K9 更彻底）。
  修复 = 单参数 `floor_rise_idle_only`（y_floor 仅空载时抬升），默认 0；置 1 后同数据漂移 **−74 ADC**，
  台阶数 30→3，16 份历史录制逐帧差 ≤3.1 ADC、10g 保留率完全不变。
  已落地为 **portable-1.1**（`03_K10_.../creep_observer_portable.h`，新旧 DLL 逐帧差 0.0）。**未下发固件。**

## 3. 当前状态快照（2026-09-27）

### 3.1 K9 的机制链（每一层修什么）

| 层 | 名称 | 修的失效 | 关键增量 |
|---|---|---|---|
| 底座 | v3.4 双态观测器 | v6 整片卸载丢基线、事件式记忆误伤 | 逐通道 `zero / x1 / x2`，`e = max(y−x1−x2,0)`，显示 `= v − x1 − x2` |
| H3 | 沿后前馈 + 软冻结 | 阶跃后 ~2 s 见峰随后回落（纯过补偿中位 262 ADC） | 沿后 2 s 内 τc1→2、`τ_slope=3→1`、`slope_gate 2%→5%`、沿后 x2 软冻结 |
| K6 | 预留池 `applied` | 快相期间把显示往下拉太猛 | 受载期施加补偿增速 ≤ 快速导数 + `hold_eps`，慢相逐步释放 |
| K7 | 棘轮修复 + 空载直通 | 反复 4~6 s 加卸载时补偿逐循环棘轮增长、空载塌向 0 | `slow_confirm_s`、`tau_r_slow_idle_s`、去趋势空载门 `y_floor`、全局总值旁路（迟滞双门限） |
| **K9** | **缓坡前馈** | 缓坡加载（0.5 < slope ≤ 60 ADC/s）不触发沿 ⇒ 只能走慢收敛路径 | 每通道 `ramp_dwell`；`w=min(ramp_dwell/4,1)`；`tc1 = tc1·(1−w) + 2·w`；斜率归零或越沿自动清零 |

> K9 在既有 10 会话上**与 K7 零行为差异**（安全冗余）；真正的增量场景是
> 斜率 20~60 ADC/s 的"陡坡但不过阈"加载，**需要补录才能证明其价值**。
