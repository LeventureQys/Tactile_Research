## 二、口径与可信度

- **E（弹性电平）**：本批力值录制的加载是 **~0.45 s 斜坡**而非理想阶跃，所以「台阶后 0.1~0.6 s 最小值」会落在斜坡中间（段1 得 12.22 N，偏低 2.7 N）。本报告主口径取 **加载斜坡结束后的平台**：`E = 输入在 [t0+0.35, t0+1.0] 的最小值`（段1 14.878、段2 15.572、03225d 13.076）。旧口径 E_fast 的落点同时列出（段1 +3.72、段2 +3.73）。
- 落点 = 段末显示 − E；下坠 = 段内峰值 − 段末；过扣 = E − 段内最小值；漂移 = 段末 − 显示(t0+0.35)；稳定时间 = 1 s 中值末次偏离落点 > 0.3 N（=300 ADC）的时刻；分析窗自 t0+0.35 s 起、段末留 0.6 s。
- **复算可信度**：离线复算器 ≡ Python 移植（逐帧 0.00000 N）；用录制参数复算 vs 录制 seg 流：**加载段内 |差| ≤ 0.0094 N**（2.0~15.6 s）、全段均差 0.049 N，唯一大差出现在 15.7~19.0 s 的**全卸载窗**（设备按 K7 空载直通整帧不扣，复算按状态泄放扣了 −1.83~−0.1 N）。该窗只影响显示不影响状态（`applied` 无反馈），19.0 s 重载后复算与录制重新吻合到 0.001 N，故不影响本报告所有保压段指标。
- 力值单位：`pre` 流（N）与 `raw/1000` 逐帧一致（最大差 0.005 N）⇒ **1 N = 1000 ADC**，力值模式通道值 ≪ 1。

## 三、力值模式的算法结构（为什么这些旋钮在 N 显示下语义变了）

`e = v − x1 − x2`；力值模式每通道 `e ≈ 0.2~0.4 N ≪ 1` ⇒ 算法里的 `base = max(e, 1) ≡ 1`：

| 量 | ADC 显示（e≫1） | 力值显示（e≪1，本报告） |
|---|---|---|
| `cap = slope_cap_frac × base` | `× e`，比例语义（ADC/s） | **绝对量：slope_cap_frac N/s·通道** |
| `hi = r_slow_max × base` | `× e`，比例语义 | **绝对量：r_slow_max N·通道** |
| 斜率门 `slope_gate_frac × base` | `× e` | **固定 0.05 N/s（非界面参数）** |

本会话 41 个受载通道（E_ch 中位 0.216 N、最大 0.448 N），总值蠕变速率 0.24 N/s（=0.0058 N/s·通道）。所以：
- `cap=0.009` ⇒ 上限 0.009 N/s·通道 = 0.37 N/s 总，**仅比真实蠕变速率高 1.5 倍**——这就是 cap 在力值模式下既敏感又容易欠跟踪的原因；
- `rsm ≥ 0.1` ⇒ 上限 ≥ 0.1 N·通道 = 7.1 N 总 ≫ 需要的 ~2.4 N ⇒ **rsm 在力值模式空转**（实测 0.10/0.20/0.35/0.60 四项结果逐位相同，见第五节④）。

**三个机制在力值模式彻底失效**（实测逐帧验证，`133_edge_check.py`）：本会话逐通道 `max|slope| = 0.574 N/s`，而沿阈值 `edge_slope_thres = 60`（ADC/s）、缓坡阈值 `ramp_slope_min = 0.5`（N/s）——**触发沿 0 帧、触发缓坡 0 帧** ⇒ 全程 `τc1 = tau_c_fast_s`（沿后 2 s 前馈与 K9 缓坡前馈都不发生），`t_edge` 恒为 1e6 ⇒ `soft_unfreeze_s` 门恒开。ADC 会话同口径下触发沿 142 帧、缓坡 2604 帧，两种显示模式的行为差异远不止 cap/rsm。

**「前 3.5 s 空窗」是结构性的**（第五节①②③，实测）：
- 空窗 = 加载斜坡 0.45 s + **非界面斜率门** `0.05 N/s`（由 `tau_slope_s=1 s` 的低通导数从斜坡峰值衰减到门下决定，≈ 台阶后 2.5~3.0 s 开门）；
- `soft_unfreeze_s` 0.1↔60 **四位小数完全相同**（死参数）；
- `slow_confirm_s` 0↔2 只差 0.066 N（门没被它卡住），≥3 才变成"纯推迟"；
- `slope_cap_frac` 在空窗内**毫无影响**：加载后 1.0 s（t=3.17 s）显示 = 16.540/16.539/16.535（cap=0.002/0.011/0.05），差 ≤0.005 N ⇒ 用户此前"cap 0.002→0.3 在 2 s/3 s 显示相同"**属结构性，不是调参不到位**；同时 cap≥0.03 饱和（0.05 与 0.3 逐位相同）。

**8 个旋钮在力值模式的实际分工**（其余全为空转）：

| 旋钮 | 角色 | 力值模式下的实测杠杆 |
|---|---|---|
| `r_fast` × `tau_c_fast_s` | **唯一的「电平扣除」**：x1 在门开前就开始把显示整体压低（x1 终值 = `r_fast/(1+r_fast)` × 读数） | rf .03→.05（τc1 2, cap .009）上漂 1.19→0.88 N，回调只 +0.03 N ⇒ **性价比最高的旋钮** |
| `slope_cap_frac` | **唯一的「跟踪速度 / 伪影闸门」**：决定台阶尾被积进去多少 | （段1）cap .008→.011（rf .03, τc1 1）上漂 1.00→0.64 N 但回调 0.34→0.60 N ⇒ 上漂与回调在此**互为代价**，约 1:0.7~1:1.0 |
| `slow_confirm_s` | 力值模式 ≤2 s 死区，≥3 s 纯推迟 | 3/5/8 s ⇒ 上漂 +1.38/+2.22/+2.85 N、回调 0.51/0.29/0.14 N |
| `soft_unfreeze_s` | **死参数** | 0.1~60 s 结果逐位相同 |
| `r_slow_max` | 力值模式 ≥0.1 空转；<0.08 变成"总扣除预算" | 0.05 ⇒ 上漂 +1.44 N、回调 0.21 N，但**末段转为 +0.051 N/s 持续上漂**（预算用尽后不再跟） |
| `tau_r_fast_s` / `tau_r_slow_idle_s` | 只管卸载/重载衔接 | τrsi 0.5 已是最优（0 ⇒ 残补带入第二段，过扣 2.38 N；≥2 ⇒ 泄放不足同样过扣） |
