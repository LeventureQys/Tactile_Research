# plan-v3.4 · 在线双态观测器原型报告（无事件 / 无记忆 / 参数全局固定）

> 核心：`scripts/v34_observer_core.py`（逐通道双 Kelvin-Voigt 状态，24 行主循环）；
> 一致性验证：`scripts/v34_observer_eval.py` → `results/v34_observer_eval.txt`；
> 全量 20 数据集：`scripts/v34_observer_plot_all.py` → `figure/observer/`（每数据一张图）+
> `results/v34_observer_all.txt`。
> 参数（全局固定，未做任何逐会话拟合）：r1=0.12/τc1=8s/τr1=6s（快态）、
> r2=0.20/τc2=300s/τr2=150s（慢态）。

## 1. 模型

```
e = max(v − x1 − x2, 0)                       # 弹性估计（受载门自然形成）
受载: x_k += dt·(r_k·e − x_k)/τk_c            # 蠕变：朝与载荷成正比的饱和值
空载: x_k += dt·(−x_k)/τk_r                   # 恢复：静置衰减
显示 = v − x1 − x2                            # = 纯弹性响应
```

无事件分类、无状态清零、无跨事件账本；跨卸载连续性来自"状态本来就不清零"。

## 3. 抗干扰 / 平坦度（保压段显示 std，输入 → 显示）

- **改善**（14/20 或持平）：7b3977 127→51 / 110→26；0cb8b6 298→131 / 98→20；
  f9740b 26→15；振荡工况 f40a1b 56→35；随机切换 31b7f9 47→27；大偏置 602c03 40→24；
  中途切换负载(B组) 298→127 等。
- **两条退化**（如实报告）：
  - `持续恒定负载`（~700 s 超长保压）219 → **338**：慢态 τ2=300 s 只能部分补偿更慢的蠕变，
    显示缓慢上爬——这是双时间常数模型的边界（真实慢相可能 ≥900 s，辨识时顶到搜索上界）；
    调大 τ2 可压平，代价是对"真实的缓慢加载"更迟钝。
  - `剧烈变化负载` 6b2e70 28 → 68：负载快速大幅摆动时 x 的滞后表现为显示偏离。
- 空载带：显示 = 输入 − 恢复中的 x，卸载后会有一段低于原始零点的回落再回升
  （例如目标录制 t240~244 段 std 76）——这是"扣除非弹性"的语义代价，见 §5。

## 5. 未关闭项 / 待用户看图拍板

1. **空载语义**：观测器在空载段会显示"恢复中的零点"（低于原始零点再回升）。
   若现场要求"空载读数原样显示"，需加空载直通门（显示=输入、x 照常演化）——
   一行改动，但会引入"空载带上显示与 x 不一致"的窗口。
2. **超长保压**：τ2 需要在"压平慢蠕变"与"跟踪真实缓慢加载"之间取舍，现场可调。
3. 参数 r/τ 为全局默认（来自规律辨识量级）；若要更优可做启动期在线辨识（前 30 s 数据），
   原型已预留接口。
4. C++ 落地形态待定：独立第七档，还是替换 v3.4 档内部实现（建议后者，菜单不动）。
