## 1. 要解决的问题（来自需求文档与三轮现场数据）

1. **恒压时漂**：加载后显示持续上爬（快相 5~30 s + 慢相 ≥100 s 量级），要求加载后 1~2 s 稳定；
2. **反复增减同一负载的一致性**（±10%·台阶可接受）：此前的 v6 在"整片卸载后重载"时把历史
   补偿清零（ToIdle），显示跳回原始读数，与前面补偿段相差 ~2000 ADC（"丢基线"）；
3. **鲁棒性**：不依赖事件账本/记忆快照（已实测会误伤变化负载工况），参数不挑数据。

## 2. 模型（物理层）

把传感器+夹具当作**线性粘弹性体**，逐通道维护两个 Kelvin-Voigt 非弹性状态：

```
y = v − zero                           # 去零点后的负载响应
y_max = 慢衰减的 y 峰值包络；idle = y < idle_frac·y_max
idle 时 zero 以 τ0 向读数靠拢（空载直通/零点再校准）；受载时 zero 冻结
e = max(y − x1 − x2, 0)                # 弹性响应估计（受载门）
x1（快态，固定模型）：受载朝 r1·e 以 τc1 收敛；空载以 τr1 恢复
x2（慢态，慢漂移跟踪）：受载时按输入的低通(τ_slope)导数积分（扣除 x1 已解释部分），
                       上限 r2max·e 钳位；沿/快变(|slope|>gate)不积分；空载以 τr2 恢复
显示 = v − x1 − x2                     # = zero + 纯弹性响应
```

- `x1` 吸收加载后数秒~数十秒的快相爬升；`x2` 吸收分钟级慢蠕变；
- **v3 关键变更（空载漂没修复）**：传感器零点偏置 ~2120 ADC ≠ 0，v2 的
  `e=max(v−x1−x2,0)` 把整个零点偏置当弹性载荷 ⇒ 全程空载的录制里状态持续生长、
  显示下沉 −315 ADC；v3 引入**零点跟踪**（近零带内慢速再校准、受载冻结）后
  空载显示≈原始读数（均值差 −20 ADC）；
- **v2 关键变更（恒载衰减修复）**：慢态不再按固定幅度 `r·e` 生长，而是**跟随实测慢漂移
  速率**——实测蠕变幅度因工况差 3 倍（7% vs 20%），固定幅度必在一边过扣（现场表现为
  恒载 5 分钟显示持续衰减）、一边欠扣；跟踪式慢态在恒载下按构造把显示钉平；
- `r1·e` 与载荷成正比 ⇒ 快态对任意负载幅度自洽（无需负载分类）；
- **无事件检测、无状态清零、无跨事件账本**：跨卸载连续性来自"状态本来连续"——
  卸载后 x 按恢复时间常数衰减，重载时残余 x 直接抵消"快相落点比首次高"的部分；
- 受载门由 `e>0` 自然形成，不需要阈值判据。

**为什么显示=弹性响应就是"无蠕变真值"**：恒载下 x1 收敛到 r1·e、x2 积分掉全部实测
慢漂移 ⇒ 显示钉在弹性电平 e（= 快相结束后的落点）；重载时 v 的快相落点 = e + 残余
非弹性，显示自动扣掉后者。

### 2.1 零点判定与启动语义（v3）

**零点不是固定值，逐通道演化**：

1. **初始零点** = 算法启用（或重置）时刻的第一帧读数。重置触发：开关切换、设备切换、
   值域签名变化——签名包含软件零偏 `ZeroOffset`，**软件调零会直接使算法全新启动**；
2. **运行中**：`y = v − zero` 落入**近零带**（< `idle_frac`·量程包络 `y_max`，相对判据、
   非绝对阈值）时，`zero` 以 τ0=8 s 向读数靠拢（空载直通 + 零点再校准）；受载
   （y 超出近零带）时**冻结**。`y_max` 是慢衰减（600 s）的 y 峰值包络，判据始终
   相对当前工况，不依赖"空载读数≈0"。

**启动方式与行为（不要求零载启动）**：

| 启动方式 | 行为 |
|---|---|
| 零载启动 | 理想：零点=真空点，一切按上文工作 |
| **带载启动 + 调零（推荐）** | 调零后读数≈0 → 落入近零带 → 零点 ~8 s 内重锚到调零状态；软件零偏变化更会直接触发算法重置（等效全新启动）。之后该负载的蠕变与一切变化正常补偿。**操作规范：装好负载 → 调零 → 开算法；或算法常开，每次调零后自动重置/重锚** |
| 带载启动 不调零 | 安全但不补偿（显示≈原始读数、随蠕变上爬，回放仿真确认：带载启用后显示≈输入逐位跟随）；后续负载**增量**正常补偿；第一次卸载后零点自动重锚到真空点，完全恢复 |

两个注意点：**调零=重定义参考**——不同调零周期之间的显示值不可直接横比（差一个
调零偏置，任何调零系统的固有性质）；调零瞬间的读数跳变被慢态沿门（|dv/dt|>2%·e/s
不积分）挡住，不会被当成蠕变吸收。

## 3. 参数（全局固定，不逐会话拟合）

| 参数 | 值 | 含义 |
|---|---|---|
| `r_fast` / `tau_c_fast_s` / `tau_r_fast_s` | 0.12 / 8 s / 6 s | 快态幅度比 / 收敛 τ / 恢复 τ |
| `r_slow_max` / `tau_r_slow_s` | 0.35 / 150 s | 慢态上限（相对弹性）/ 空载恢复 τ |
| `tau_slope_s` | 3 s | 慢漂移速率估计的低通时间常数 |
| `slope_gate_frac` / `slope_cap_frac` | 0.02 / 0.01 | 沿门（超过 2%·e/s 不积分）/ 积分速率上限 |
| `tau_zero_s` / `idle_frac` / `y_max_tau_s` | 8 s / 0.05 / 600 s | 零点跟踪 τ / 近零带宽 / 量程包络衰减 τ |

定标依据：三个反复增减录制的规律辨识（`规律辨识报告.md`：双 τ 结构、快相幅度与载荷
成正比）；慢态幅度不设固定值（实测因工况差 3 倍，v1 固定 0.20 在新恒载录制上过扣、
表现为 5 分钟持续衰减 −356 ADC，v2 改为跟踪式后 −50）。参数经
`CreepObserverCompensator::Params` 可运行期注入；录制 manifest 落盘
`param_set = "plan-v3.4 observer-v3"`（11 字段）。

## 4. 实现（软件层）

| 文件 | 职责 |
|---|---|
| `src/domain/drift_v6/creep_observer.{h,cpp}` | 算法本体 + `CreepObserverCoordinator`（按目标 key/值域签名隔离，开关切换全重置） |
| `src/data/data_handler.{h,cpp}` | 挂载：串口与无线两条显示路径（单位换算后、阈值过滤前、回放旁路）；与 v6 档互斥路由；录制算法 id/参数落盘 |
| `src/ui/menubar.cpp` | 菜单「时漂/零漂补偿（v3.4 观测器）」+ tooltip |
| `src/app/application_controller.cpp` | 开关投递数据线程 + 状态栏提示 |

逐帧流程（每通道，dt=clamp(Δt,0,0.1)，重复时间戳只施加不积分；首帧 v_lp 用输入初始化）：

```text
y = v − zero；（近零带内 zero ← zero + dt·(v−zero)/τ0）
e_now = max(y − x1 − x2, 0)
dx1_rate = (e_now>0) ? (r1·e_now − x1)/τc1 : −x1/τr1     # 快态斜率（用更新前的 x1）
x1 ← max(x1 + dt·dx1_rate, 0)
slope = (v − v_lp)/τ_slope；v_lp += (dt/τ_slope)·(v − v_lp)  # 低通导数（解析式）
e = max(y − x1 − x2, 0)
if e>0:
    if |slope| < gate·max(e,1):                        # 沿/快变不积分
        x2 += dt·clamp(slope − dx1_rate, ±cap·max(e,1))
    x2 ← clamp(x2, 0, r2max·max(e,1))
else:
    x2 ← max(x2·(1 − dt/τr2), 0)
显示 = v − x1 − x2            # 不做正值钳位、不做归零（空载显示"恢复中的零点"）
```

内存：每目标 3×通道数个 double（x1/x2/v_lp），无环缓（对比 v6 约 2 MB/目标）。

## 6. 已知边界（如实）

1. **空载语义（v3 已改直通）**：空载时零点慢速再校准、显示≈原始读数；**卸载后到
   零点重新校准完之前**（τ0=8 s 量级 + x 恢复），显示会有一段低于原始零点的过渡；
2. **带载启用不调零时不补偿**（安全侧，见 §2.1）：显示≈原始读数直到第一次卸载或调零；
   需要补偿请先调零（推荐操作规范见 §2.1）；
3. **慢态会吸收真实的缓慢加载**（≤1%·e/s 且连续）：这是"恒载钉平"的另一面，
   由 `slope_cap_frac` 限幅；存在持续缓慢加压的工况需注意；
4. **快相收敛**：首次加载 ±2% 带 ~5 s、受载态小台阶 7.5~15 s——缺快相前馈
   （下一轮方向：沿后用形状先验直接置 x1 到预测终值，预计小台阶 2~4 s）；
5. **参数为全局默认**：换传感器/夹具建议重标 r/τ（规律辨识脚本 `v34_law_identify.py` 可复用）。
