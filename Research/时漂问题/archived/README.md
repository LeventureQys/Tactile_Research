## 复现须知（重要）

`历史版本/` 内部的脚本按**当时**的目录层级书写，例如
`06_K12_旧实验归档_2026-10-13/scripts/k12_v2_run.py` 用
`ROOT.parents[1] / 'data'` 定位录制数据。

整体下移到 `archived/` 之后，这些相对锚点会**多算一级**（指向 `archived/data` 而非 `时漂问题/data`）。
归档层按只读处理，**未逐个回改**。需要复现时：

- 优先修**相对锚点**：把 `parents[N]` 调整为 `parents[N+1]`，或在脚本顶部改成绝对路径；
- 或从数据侧对齐：确认脚本期望的 `data/` 位置与实际 `时漂问题/data/` 一致。

`K12对照_右拇指专项_20261013/` 与 `参数细调对照_20261014/` 这两个较新的归档，已在归档时
同步修正了对彼此的引用，其脚本可直接运行（依赖 `data/`、`archived/历史版本/`）。

已修正的引用：

| 文件 | 修正内容 |
|---|---|
| `K12对照_右拇指专项_20261013/guard_trial.py` | 依赖目录 → `archived/历史版本/06_K12_旧实验归档_2026-10-13/scripts` |
| `K12对照_右拇指专项_20261013/replay_study.py` | 数据根 `parents[2]` → `parents[1]`（原值本就指向不存在的 `Research/data`） |
| `参数细调对照_20261014/routeb_fair_probe.py` | 依赖目录 → `路线B_趋势预测平台重建_20261013` |
