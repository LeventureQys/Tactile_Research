## 1. 本目录重算（已执行过一次；只读录制 CSV，只写本目录）

```powershell
cd temp\v4.1flash\plan\v3.2-gpt5.6
$env:PYTHONIOENCODING='utf-8'
python recompute_metrics.py
```

**输入（只读）**

| 文件 | 角色 | 说明 |
|---|---|---|
| `temp\算法数据&原始数据\working\零基线-反复增减同一负载\20260919_160854_single_device_7b3977\device_001_pre_seg0.csv` | 算法输入（`stream_role = algorithm_input`） | 31334 行；**表头只有 3 个列名，数据行 24 列** ⇒ 通道按位置 `f[3:24]` 取 |
| 同目录 `device_001_seg000.csv` | 算法结果（现场显示） | 31331 行；表头齐全 |
| 同目录 `session.json` | 现场参数集 | `algorithm.params.param_set = "plan-v3.0 PCT"`（**不是 v3.4**，见 `调查报告.md` 前提 1） |

**输出（本目录）**

| 文件 | 内容 |
|---|---|
| `event_evidence_raw.csv` | 20 个输入沿（0.8 s 内合并）：前后电平、台阶、最大单帧跳变、2.5~8 s 与 5~20 s 落定窗 |
| `shape_15s_vs_245s_raw.csv` | 15.18 s / 63.41 s / 245.27 s 三条沿的输入+显示形状对齐（按本段落定增量归一） |
| `edge_zoom_245s_raw.csv` | 244.6~246.4 s 逐帧明细（`t, dt, sum_in, sum_out, ded, d_in, d_out`） |
| `事件证据.csv` | 交付用汇总：现场重算 + v3.4/v3.6 回放引用值（每行带 `src` 出处），**本脚本会重写它** |

**口径（改脚本前先读）**

- 总量 = 21 通道之和；`ded = sum_in − sum_out`。
- 沿检测：`|Δsum_in| > 1200`，且相邻候选帧间隔 ≤ 0.40 s 归并为同一沿。
- 落定窗：沿后 2.5~8 s 均值（E6 因 252 s 处含部分卸载，改用 247.8~253 s）。
- 形状：`(s(t0+Δt) − s(t0−0.5s 前均值)) / (s(t0+20s 附近均值) − 基准)`。
- `dt` 列经常为 0（**同一 `elapsed` 压 3~4 帧，实测 `dt = 0` 的帧占约 70%**）⇒ 不要用 `dt` 做微分。
