## 一句话结论

用户报的「245 s 之后丢基线」在**当前 v3.4 源码里已部分修好但未收敛**：245.27 s 的重载**没有漏检**（输入/输出台阶一致），失败点在 **交接后扣除接近归零 + 锚定的"无蠕变电平"错了约 1800~2000 ADC**；`plan-v3.4` 的蠕变记忆把缺口从 ~2000 ADC 压到 ~256 ADC（−11%），而候选 `plan-v3.6`（seed 只在一处施加）把同一负载前后差压到 −26 ADC。**候选尚未落地产品源码、未做真机 A/B、且在域外工况（随机切换）有已量化的副作用。**

## 口径声明（跨口径不可横比）

1. **参数集**：现场录制 = `plan-v3.0 PCT`；当前源码 = `plan-v3.4 creep-mem`；候选 = `plan-v3.6`。**三者不可直接横比**（自有记录起就写明这一点，见 `progress/currentworking/02_算法更新日志.md` §R3）。
2. **量纲**：总量 = 21 通道 ADC 之和；`ded = 算法输入(pre) − 显示(seg000)`。
3. **"台阶保真" G** 有两种口径：`G`（[3,5] s Δ显示/Δ输入）与 `Gd`（卸载沿）。本目录凡引用一律带口径与臂名。
4. **回放 ≠ 现场**：录制开始前算法已在运行，前置历史不在文件里（同工况实测中位 |Δ| 1482 ADC）⇒ 臂间对照有效，绝对电平对现场需同口径并报。
