## 问题定义

**现象**：在「零基线-反复增减同一负载」场景中，经历长保压(153s)后的加载周期与之后全新开始的加载周期（如 t=245s）相比，算法输出值差异巨大（~2400 ADC）。后续变载周期几乎无补偿（ded ≈ 0）。

**根因**（两层，v3.2 已定因第一层，v3.3 补充第二层）：

1. **Handoff 锚定失效**（v3.2 定因）：完全卸载→重载时，交接把 `A` 钉在平台上 → `g_raw≈0` → 补偿归零
2. **PCT 无界累积**（v3.3 补充）：PCT 在 153s 保压中累积 -2395 ADC，ToIdle 时突然清零，造成显示不连续

---

## 修复方案：两条正交修改

### 修改 R1：v3.2 的种子注入（主修复）

**解决**：重载后补偿归零的问题。

详见 `../v3.2/问题清单.md` §3。核心是：
- 新增会话级蠕变比记忆 `creep_ratio_`（跨卸载保留，空载期按 τ=45s 衰减）
- 重载时注入蠕变种子 `seed = 0.70 × creep_ratio_ × inc_max`
- 交接时 `A_new = y0 + share·(Â − seed)` 把蠕变从无蠕变电平里扣掉

**已验证效果**：245s 重载补偿 −78 → +1175 ADC（≈首次加载的 72%）。

产品代码改动需从 `../v3.2/src_v32/` 移植到 `src/domain/drift_v6/`。

### 修改 R2：PCT 自然衰减（补充修复，降低累积量）

**解决**：PCT 在长保压中无界累积导致的跨周期一致性问题。

**位置**：`src/domain/drift_v6/drift_v6_compensator.cpp` SlowStep 中 PCT 积分部分

**修改**（第 967~968 行之间，clamp 之后、赋值之前）：

```cpp
// 现有代码：
                if (d < lo) d = lo;
                if (d > hi) d = hi;
// ───── v3.3 新增 R2 ─────
                // PCT 自然衰减：限制长保压累积量，改善跨事件一致性。
                // d(pct)/dt = (1/τ_pct)*resid − (1/τ_decay)*pct
                // τ_decay=45s: 前20s影响<10%，60s后限制累积至~83%。
                // = 0 时不衰减，与 plan-v3.1 行为逐位一致。
                if (params_.pct_decay_tau_s > 0.0)
                    d *= (1.0 - dt / params_.pct_decay_tau_s);
// ───── 新增结束 ─────
                pct_ded_(k) = d;
```

**新增常量**（`drift_v6_compensator.h`，在 `kPctMono` 之后）：
```cpp
static constexpr double kPctDecayTauS = 45.0;  // PCT 自然衰减时间常数(秒); 0 = 不衰减
```

**新增 Params 字段**：
```cpp
double pct_decay_tau_s = kPctDecayTauS;  // 0 = 关闭（回到 plan-v3.1 行为）
```

**参数落盘**：`data_handler.cpp` 新增 `pct_decay_tau_s` 字段。

### 参数集
