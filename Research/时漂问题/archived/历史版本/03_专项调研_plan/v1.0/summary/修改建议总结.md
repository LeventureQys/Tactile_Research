> **来源**：`../总报告.md`（§5.2.1 / §6.3 / §7 / §10.3）为主，辅以 `../T8_v6总体评估与路线裁决/t8_verdict.md`（§3 / §4 / §8）。
> **性质**：只做归纳，不新增结论；两处数字冲突以 `总报告.md` 为准（见文末「版本口径提示」）。

## 0. 一句话总纲

**不推翻 v6、不退回 v5.1，而是上「方案 A」= v6 + 六项改动**（4 项为一行常量/零代价，全部不需要新增现场标定）。
理由：v6 的「快」来自「形状先验预测 + 冻结显示」（纯跟随器稳定下界 4.70 s，而 v6 在 8/8 事件上快于它），
**机制不能动、也不必动 —— 只要给「预测」加三道安全阀**（限幅 / 清零 / 判据鲁棒性）。

**但要同时接受两条硬事实**：
1. 「1~2 s」**只能是中位承诺**（v6 中位 1.80 s、达标率 5/9 = 55.6%、最坏 13.16 s），**不是上限承诺**；
2. 若「可重复性 / 强扰动稳定性」才是验收硬指标，**方案 Z（不动）反而是理性选择** —— v5.1 在这两维上全面优于 v6。

### 1.1 预期组合效果（口径：T1-A 冻结 `T_stable_ch5`）

| 指标 | 现状（v6） | 上方案 A 后（预期） |
|---|---|---|
| 恒载 onset `T_stable` 中位 | 1.80 s | **≈0.55 s**（主通道口径按同比例估 ≈0.6~0.8 s） |
| 尾部（最坏折） | 78.50 s 量级 | **≈5.36 s** |
| ≤2 s 达标率 | 55.6%（5/9） | **预期 ≥67%** |
| 过充中位 | +9.64% | **≈ −3%（转欠报）** |
| 最大偏差 `MD` 中位 | 2396.7 ADC | **≈555 ADC（−77%）** |
| 路径抖动（±1 包） | 7.90%·电平 | **≈0.7~1.2%·电平（−85%）** |
| 拍击永久基线损伤 | 22.4% 电平 | **0.96% 电平** |
| 台阶捕获比 `G` | 1.033 | **≈0.98（略钝）** |

⚠️ **「预期」列中凡涉及多改动叠加的都是合成外推、不是实测** —— 验收必须以真机 A/B 为准。

### 1.2 上线顺序与三个必须先过关口

```
第 1 步（天级，零风险，先上）
    A1 κ_onset=1.05      ← 一行常量，风险最低、收益最大（尾部 ~40 倍）
    A2 过充硬限幅 0.02   ← 显示层封顶，不磨台阶
    A5a I7 撤销迟滞 3 帧 ← 零代价，对 L2 / T_stable 逐位中性
    ↓ 真机 A/B：核对最坏事件、过充方向（是否转为欠报）、抖动重复性
第 2 步（需 1 次真机确认）
    A4 HO_MIN 3.5 s      ← 复核 07-v6 的 3~9 s 暂态注释
    A5b τ_ho 5→10 s      ← 【前置】必须补验两条边界
第 3 步（需状态机改动 + 专项测试）
    A3 清 c0             ← 「负载内变载」能不能用的开关
    A6 低置信期冻结锚定  ← 需现场标定阈值
```

1. **`τ_ho ≥ 10 s` 在「加载后 10 s 内再次变载」工况下未验证**（变载实录里很常见）⇒ A5b 不要单独先上，先上 A5a。
2. **`I7` 对「真实单帧掉点必须快速撤销」的用例样本只有 1 处** ⇒ 上线前做「掉点 vs 拍击」判别测试。
3. **`HO_MIN` 早交接暂态**（07-v6 注释的 3~9 s）在聚合口径下未见恶化，但属单事件观察 vs 聚合的尺度差 ⇒ 真机 A/B 复核。

## 3. 明确「不推荐」清单（含原因）

| 不推荐 | 原因（实测） |
|---|---|
| **加输出端 EMA / 中值滤波** | 第一轮「双赢」作废：`T_stable` **0.54 → 1.24 s（变差）**、`MD` **1440 → 4211 ADC（最大 26826）** —— 把「过充峰值」换成了「显示与原始读数的瞬时失配」（第一轮没报 `MD`，代价当时不可见）。内部状态层滤波更差（`G` 掉到 0.438、过充中位翻成 −47%、`T_stable` 出现 NaN） |
| **抬 `ratio` 门限**（现行唯一旋钮） | 保持维 AUC **0.841**，而抬 ratio 的 AUC **0.402 —— 比随机还差**。正确维度是「平台/保持」，不是门限 |
| **驻留确认（dwell）作默认改动** | T5-B 推翻：存活伪事件 **0.500 → 1.000**、留下 >20% 永久锚点损伤的拍击占比 **21.4% → 42.9%**；Pareto 非支配点只有「现状（0.10 s, 0.500）」与 0.58 s 档 |
| **CAPF（`5σ_d` 用 5% 电平封顶）** | 三方独立复现为**有害**：误触发 0.5 → **14.6 次/录制**、epoch 8 → 23.6 |
| **rescue 救援检测器** | 原型级实测**零收益**（触发 10.1 次、漏检 3.5 不变） |
| **调 `RATE_MAX` / `REVOKE` 四旋钮** | **三方独立互证无效**：T6 消融 Δ = 0.0000、T3-B 速率 0.3~3.0 整段无效、T5-A 不绑定 ⇒ **建议删掉以简化状态空间** |
| **为两种快相形态加分支**（硬分支或连续参数化） | 真值分支上界 `ΔT_stable` = **0.000 s**；连续参数化（参数取对、窗口 0.60 s 足够）平台偏差最坏 **4.2%·幅度且方向不一致**。⇒ 归入「范围界定项」，**不产生收益** |
| **`ROM_SCALE` 与 κ 同时上** | 二者**同类**（都压 `Â`）⇒ **会过度欠报**，**二选一** |
| **重新引入「空载自动归零」** | 会把零点改到 **−552~+552 ADC**，是传感器自身零漂的 **6~30 倍**；现役 v5.1 删掉它是正确的 |

## 4. 验收口径与纪律（比旋钮更能决定结论）

1. **口径冻结**：一律用 **`T_stable_ch5`（主通道 + 5 s 参考版）+ 100 Hz 严格网格**；换口径差 **3.6 倍**，0.3% 网格差即可**翻转**「谁更可重复」。任何排名必须连同**口径 + 网格 + 删失率 + 样本集**一起给出。
2. **两个数字必须并报**：`T_stable` **与显示偏置**。否则会把「停在错的地方」读成「变稳了」（噪声 `r=2%` 时 `T_stable` 0.53 → 0.39 s 变好，但显示持续静偏 **12.8% 电平**）—— 这是本项目第 8 个、也是最危险的口径陷阱。
3. **验收承诺改为三句可验收的话**（不要给「1~2 s」统一承诺）：
   - 守恒载单次加载：承诺 **中位 ≤2 s、达标率 ≥55%**（当前 v6 水平）；「最差 ≤2 s」**当前实现不满足**；
   - **restep：不要用 `T_stable` 验收**（指标结构性失效：容差/噪声中位仅 1.20，9/19 个 <1）。改用**事件级指标**（事件后 1 s / 2 s 偏差 + `G` + `MD`）；
   - 卸载：达标（9/9，中位 0.09 s），可承诺 ≤1 s；但卸载后的零点行为按 T7 结论单独处理。
4. **三指标并看**：`T_stable` / `OS%` / `MD`。单用 `MD` 会误判（`clean` 子样本上「真值分支」的 `MD` 反而更差）；`OS%` 在 restep 上会因归一放大到 330~480%，必须与「÷事件绝对幅度」口径并读。
5. **每个收益给两个数**：乐观（自身标定 3.10%）/ 悲观（留一 5.52%、跨族 5.33%、**跨形态 56.39%**）。凡是「不能超上限」的承诺一律用悲观。
6. **改动必须逐项上、逐项验**，且先用 A/B 零差证明「补丁不改变默认行为」（范式：逐帧输出最大绝对差 = 0.000e+00 → PASS），并配**阳性对照**证明自检有灵敏度。
7. **优先压判据延迟、再动形状库**：稳定时间的主要障碍是 v6 内部判据/估计延迟（`TAU_REF 0.20 + STALL_HOLD_S 0.45` = **0.65 s 下界**）+ 传感器粘弹，**不是**「输入没走完」（全样本 restep 等效斜坡中位仅 0.220 s）。
8. **根上的靶心是形状库可信度**：改进方向是「**约束 `m` 的离散**」（现场自标定 / 上包络重标 / trim 目标改为绝对稳），**不是「增加一个分支」** —— 与单侧门、乐观性折扣指向同一处。

## 5. 需要用户确认 / 需补采

**★ 唯一待确认项（P0，5 分钟）**：**现场 exe 到底是 v6 还是 v5.1？**

## 6. 已知局限（须与结论同读）

1. **方案 A 的多改动叠加是「合成外推」，非实测** —— 各改动由不同席位在各自口径下单独测得，组合效果未验证；
2. **算法级实验用 Python 原型，不是 C++ 现役实现** —— 滑行器与慢相模块的 C++↔原型对拍**未做**（只核对过检测器常量 45+ 条）；
3. **所有 ±A 扰动结论来自注入而非实测**；
4. **图件未做人工目视核对**（执行环境不支持读图，只做程序化校验）；
5. **`T_stable` 网格敏感**（配对差稳健、绝对排名不稳健）；**`err_1s` 对 `t_on` 的 ±1 包极敏感**（绝对值不可跨报告引用）；
6. 本报告与各席位报告冲突时，**以 `T8_*/results/t8_reconciliation.csv` 与 `00_共享/接口冲突登记.md` 的裁决为准**。
