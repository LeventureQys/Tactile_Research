## 5. 跨数据集核查（`results/v32_crosscheck.txt`，数据根下全部 8 条）

判据：**没有"卸载→重载"的录制应当逐位不变**（冷启动 `creep_ratio_=0` ⇒ 无种子）。

| 数据集 | 帧数 | 差异帧 | max\|Δ\| | ded 中位 v3.1→v3.2 | G v3.1→v3.2 |
|---|---|---|---|---|---|
| archived/从零基线开始-恒定负载-反复加减同一个负载 | 33908 | **0** | 0 | −68 → −68 | 1.008 → 1.008 |
| archived/各种奇怪工况 | 13160 | **0** | 0 | 19 → 19 | 0.989 → 0.989 |
| archived/恒定负载下反复加减同一个负载 | 6296 | **0** | 0 | 0 → 0 | 1.000 → 1.000 |
| archived/持续恒定负载 | 70156 | **0** | 0 | 1180 → 1180 | — |
| archived/零基线-反复增减同一负载（同族录制） | 34460 | 4211 | 3076 | 3334 → 3334 | 0.877 → 0.877 |
| **archived/零负载-随机切换工况** | 8080 | 1590 | 485 | 261 → **414** | **0.825 → 0.680** |
| working/零基线-剧烈变化负载情况 | 6836 | 2423 | 356 | 0 → 10 | 1.002 → 1.002 |
| **working/零基线-反复增减同一负载（目标）** | 31306 | 5774 | 1656 | 2183 → 2183 | 0.926 → **0.859** |

读法：
- **4 条逐位不变**（3 条 + 长时恒载）⇒ R1 对"没有真实卸载-重载"的录制**零影响**，无副作用；
- 同族录制 `152749` 的 ded 中位逐位一致（3334 → 3334）、G 逐位一致 ⇒ 该类工况的**中位行为未被改动**，
  只改了"卸载-重载"这一小段；
- **代价集中在两条"依赖 G"的录制**：目标录制 0.926 → 0.859、`零负载-随机切换工况` 0.825 → 0.680。
  后者是本轮最需要注意的一处——那是"零负载下随机切换"的域外工况，补偿量被抬高（261 → 414）。
  ⇒ **全量 G 口径回归与真机确认必须做**（未关闭项 4）；若真机观感变差，把 `creep_seed_gain` 再降到 0.5
  即可回到"半量"补偿（245 s：1175 → 750）。

## 7. 验收结论

| 项 | 结果 |
|---|---|
| 245 s 重载后是否恢复补偿 | **是**（−78 → +1175，占首次加载 72%） |
| 是否影响首次加载/正常工况 | **否**（前 4 次加载逐位相同；4 条录制逐位相同） |
| C 限幅硬不变量 | **保持**（0 越界） |
| 台阶保真代价 | 目标录制 G 1.004 → 0.970（单沿口径）/ 0.926 → 0.859（全沿口径）；`零负载-随机切换` 0.825 → 0.680 |
| 短保压后的部分卸载-重载 | **未解决**（261.7 / 289.3 s） |
| 验证范围 | 8 条录制离线回放；**未做真机 A/B、未改产品源码、未写单元测试** |
