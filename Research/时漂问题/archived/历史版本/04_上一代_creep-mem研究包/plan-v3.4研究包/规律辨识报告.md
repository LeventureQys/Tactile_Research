# plan-v3.4 · 规律辨识报告：反复增减负载是否服从可总结的物理律

> 数据：三个「反复增减同一负载」录制（working/7b3977、archived/0cb8b6、archived/f9740b），
> 逐会话独立辨识 + 留一法（LOO）诚实检验。脚本 `scripts/v34_law_identify.py`，
> 数值 `results/v34_law_identify.txt`，图 `figure/v34_粘弹性规律辨识_7b3977.png`。
> 背景：用户判断"反复增减的数据规律可以总结、不能靠记忆"，本报告验证这一判断的定量边界。

## 1. 模型（线性粘弹性叠加律，零记忆、纯参数化）

```
y(t) = E(class) + x_fast(t) + x_slow(t)
受载:  x_k → r_k·(E[class]−E[0])，时间常数 τk_c   (k = fast/slow)
空载:  x_k → 0，时间常数 τk_r
```

9 参数/会话；观测 = 全部平台内部采样点（同时约束落点、保压蠕变、零点漂移、重载落点）。

## 2. 结果

| 会话 | 全轨迹残差 RMS | 留一预测段电平 \|误差\| 中位 | 朴素基线（用上一次同类电平） |
|---|---|---|---|
| 7b3977 | 803 ADC (4.5%) | **935** | 2353 |
| 0cb8b6 | 777 ADC (4.4%) | **1532** | 2074 |
| f9740b | 987 ADC (5.6%) | **1062** | 2076 |

跨会话参数：τ_fast_c ≈ 5~30 s、τ_slow_c 多次顶到搜索上界 900 s、r_slow 0~0.34、
τ_slow_r 16~900 s——**参数跨会话不稳定，辨识度有限**。

## 3. 结论（定量边界）

1. **规律确实存在且可提取**：参数化模型对"下一次加载会落在哪"的预测比朴素基线好
   1.4~2.5 倍（LOO 误差 935~1532 vs 2074~2353 ADC）——用户的判断成立。
2. **但纯规律的可预测精度 ~1000 ADC**：与"约定 A（每次加载自己的落点）"的天然一致性上限
   （满载族极差 1104）同量级。即：**完全零状态的规律驱动算法，一致性上限 ≈ 约定 A**。
3. **要达到约定 B（完全可重复显示），数学上必须有跨卸载延续的状态**。关键区分：
   - 事件式"记忆"（已归档）：快照某次卸载的账本 → 伤害鲁棒性（用户批评正确）；
   - **规律驱动的状态**：状态 = 材料非弹性应变，其演化规律 = 上面辨识出的时间常数，
     在线辨识、跨卸载自然连续、无需知道"发生过哪次事件"。这不是记忆，是观测器。

## 4. 建议的下一步（待拍板）

**在线双态观测器慢相**：逐通道维护 (x_fast, x_slow)，参数 (r, τ) 由保压段数据在线辨识
（不用离线标定、不依赖事件分类）；显示 = 输入 − x。预期：
- 反复增减工况：跨卸载连续 → 逼近约定 B 的一致性；
- 变化负载工况：状态跟随材料而非某次负载 → 无"记忆误伤"；
- 辨识不出的残余（~800 ADC）以约定 A 精度兜底。
