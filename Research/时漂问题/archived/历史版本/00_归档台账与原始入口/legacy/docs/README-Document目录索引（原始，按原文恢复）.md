## 30 秒速览

**v5 = v3 + 4 处定点修复**（修的是实测暴露的确定性缺陷，不是调参）：

| # | 缺陷（现役 v3 存在） | 症状 | v5 |
|---|---|---|---|
| P1 | 负载内变载的**有效识别门限被 EMA 分离增益放大到 ≈27% 电平** | 小台阶被当蠕变扣掉 → **显示被"拉回"原读数** | 增加短滞后电平差判据，门限降到 **5%** |
| P2 | restep 把**旧载已累积的蠕变锁进新基线** | 台阶稳定后**永久偏高 +5~8%** | 基线扣除已生效的蠕变 |
| P3 | v4 的免责期**只覆盖空载→负载** | "变载也免责"从未生效 | onset 与 restep 都生效 |
| P4 | v4 原型在免责期内**跳过状态机、丢掉旧扣除** | 免责期内无法识别卸载；变载瞬间跳变 | 插在状态机之后，输出 `Z − carry` |

**实测收益**（4 份实采录制、11 个有效负载内变载事件，免责 3s）：台阶捕获比 0.89 → **0.98**；
全程最大偏差占峰值 31.3% → **9.0%**（13ffca 18.9% → 8.8%）；变载窗最大偏差中位 2464 → **1681 ADC**。

**合成砝码场景**（10N 保压 280s 后加 2.5N / 5N / 10N）：偏差 −19.9% / +7.9% / +5.9%
→ **−0.1% / −0.0% / +0.1%**。

**代价**：恒载 9 组基准 全段 **1.88%**（v3 1.58 / v4 2.60）、慢相段 **1.61%**（v3 1.49 / v4 0.95）。

**落地状态**：已实施到 `src/domain/drift/drift_compensator.{h,cpp}`（`build-app` Debug 增量构建 exit 0），
并与 Python 原型逐帧对拍（3s / 5s 两档 ≤ **5e−07**）；**未做真机/界面手测**。

**界面入口**：菜单「设备 → 时漂/零漂补偿（无责 3s）/（无责 5s）」，两项互斥、再点已勾选项即关闭；
免责期长度运行期可切（`SetFastPhase`），切换时补偿状态自动重置。

**推荐参数**：`kLevRel = 0.05`、`kLevFastS = 0.3`、`kLevLagS = 0.5`、`kLevArmS = 3.0`、
`kFastPhaseS = 3.0`（免责 3s）、幅度采集窗 `[2.0, 3.0] s`。
> 免责 3s 与 5s 的取舍见 `05-v5算法说明.md` §4.7：**长保压指标 3s 更好、变载跟踪指标 5s 更好**。
