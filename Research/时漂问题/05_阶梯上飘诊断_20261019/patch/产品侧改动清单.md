## 1. `src/domain/drift_v6/creep_observer.h`

```cpp
        // ── y_floor 抬升门（缺陷修复，2026-10-19）──
        // 原实现里 y_floor 的**抬升**分支无条件执行（以 y_floor_tau_s 慢爬向 y0），只有
        // **下行**分支受 guard 约束。长恒载（>20 min ≈ 4τ）下 y_floor 追平 y0，把载荷本身
        // 吸收进基线：(y0 − y_floor) 只剩噪声量级 → idle 判据 (y0−y_floor) < idle_frac·span
        // 被单帧噪声下沿击穿 → zero 以 tau_zero_s 吞掉整个载荷 → e≡0、x_slow 按
        // tau_r_slow_idle_s 泄放 → 补偿永久归零，显示逐通道阶梯式上飘到原始电平。
        // 2026-10-19 拇指指腹 48 min 恒载实测：输入只漂 +314 ADC，输出漂 +3431 ADC
        // （26.67 min 起崩塌）；置 1 后同一数据漂移 −74 ADC，全程补偿存活。

        // 与需求文档 §5.1「零点只在高置信度空载/近零状态下更新，受载时冻结」一致。
```


## 2. `src/domain/drift_v6/creep_observer.cpp`

把 `Process()` 中 `── ① 零点跟踪 + 去趋势空载门 ──` 的循环体整段替换为：

```cpp
        // ── ① 零点跟踪 + 去趋势空载门（K7 去趋势门限）──
        // y_floor 跟踪 y0 慢速最小值（基线），判据为 y0 − y_floor < idle_frac·(y_max − y_floor)。
        const double y_decay = std::exp(-dt / params_.y_max_tau_s);
        const bool guard_on = params_.guard_enable != 0;
        for (int k = 0; k < n; ++k) {
            const double y0 = v(k) - zero_(k);

            bool floor_down = false;
            if (y0 < y_floor_(k)) {
                floor_down = true;
                // 下行：原实现瞬时跟随（卸载/基线下漂立刻跟）；防护开启时需持续确认，
                // 深度跌破（真实卸载）立即跟随、不引入延迟。
                if (guard_on) {
                    below_elapsed_(k) += dt;
                    const bool deep = (y_floor_(k) - y0) > params_.guard_floor_deep;
                    if (deep || below_elapsed_(k) >= params_.guard_floor_confirm_s) {
                        y_floor_(k) = y0;
                    }
                } else {
                    y_floor_(k) = y0;
                }
            } else if (guard_on) {
                below_elapsed_(k) = 0.0;
            }

            y_max_(k) = std::max(y_max_(k) * y_decay, std::max(y0, 0.0));

            // 抬升：原实现无条件慢爬；floor_rise_idle_only 打开时只在本帧判为空载时抬升，
            // 受载期间冻结（防长恒载把载荷吸进基线）。
            if (!floor_down) {
                bool allow_rise = true;
                if (params_.floor_rise_idle_only) {
                    const double span0 = std::max(y_max_(k) - y_floor_(k), 1.0);
                    allow_rise = (y0 - y_floor_(k)) < params_.idle_frac * span0;
                }
                if (allow_rise) {
                    y_floor_(k) += (dt / params_.y_floor_tau_s) * (y0 - y_floor_(k));
                }
            }

            const double span = std::max(y_max_(k) - y_floor_(k), 1.0);
            const bool idle = (y0 - y_floor_(k)) < params_.idle_frac * span;
            load_dwell_(k) = idle ? 0.0 : load_dwell_(k) + dt;
            if (idle) zero_(k) += (dt / params_.tau_zero_s) * (v(k) - zero_(k));
        }
```

> 与 C++ 现役版逐字对照：`inverted`/`guard` 分支、`y_max` 更新、`span`/`idle`/`load_dwell`/`zero`
> 的语义与顺序完全保留；唯一新增的是 `floor_rise_idle_only` 对**抬升**分支的放行判断。
> `floor_rise_idle_only=0` 时 `allow_rise` 恒为 true，与原实现逐帧一致。

## 4. 开启方式与取值

| 参数 | 取值 | 推荐 | 说明 |
|---|---|---|---|
| `floor_rise_idle_only` | 0 / 1 | **1** | 0 = 现役行为（长恒载会崩）；1 = 修好后行为 |

- 没有增加新的时间常数或阈值，不存在需要现场标定的量。
- 与 `guard_enable`（K10 档）**正交**，可任意组合：`gate=1, guard=0` 与 `gate=1, guard=1`
  在本会话上差 ≤0.4 ADC（见报告 §6.3）。
- 若要按需求文档 §3.6「新增参数默认不改变现有行为」执行，则保持默认 0，
  在「算法工作台 → 抗时漂页」下发 `floor_rise_idle_only=1`；
  若确认要一次性根治，将 `Params` 默认值改为 1 并同步 `dv6_params_default()` 的默认值。
